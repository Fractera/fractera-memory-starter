# Откуда этот навык и как он обновляется

**Эта папка — ЧУЖОЙ КОД, вендоренный намеренно. Ни один файл здесь не правится руками.**
Ручная правка живёт ровно до следующего обновления и исчезает без следа — молча, потому что
обновление перезаписывает, а не сливает. Всё, что говорим МЫ, живёт в `../use-skill-creator/SKILL.md`,
он наш и не перезаписывается никогда.

| | |
|---|---|
| навык | `skill-creator` — Anthropic: как создавать, править и измерять навыки |
| поставлен как | **копиями, а не симлинками** — симлинк в репозитории, который клонируют на Windows, это отсутствующий файл, а не ссылка |
| проверено | `find -type l` даёт 0 |
| взят из | `fractera-next-starter/.claude/skills/skill-creator`, где лежит с 2026-08-21 |
| поставлен сюда | 2026-09-09 |
| размер | 256 КБ, 18 файлов |

🛑 **В ИСТОЧНИКЕ ЭТОГО ФАЙЛА НЕТ.** В `fractera-next-starter` навык лежит без `SOURCE.md` —
происхождение не записано, команда обновления неизвестна. Это нарушение нашего же закона о
вендоринге, и оно **остаётся долгом там**; здесь оно исправлено.

## Кому он тут нужен и кому нет

🔒 **ЭТО НАВЫК ДЛЯ РАЗРАБОТЧИКА, А НЕ ДЛЯ АГЕНТА ПАМЯТИ.** Агент памяти разбирает фразу человека и
не создаёт навыков; открыв этот файл, он потратит ход на документ, который ему ни к чему.
Его собственный список навыков перечислен в `CLAUDE.md` поимённо и этого имени не содержит.
