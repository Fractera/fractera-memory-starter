# AGI-CONFIG — реестр признаков памяти

**Имя папки назвал владелец 2026-09-14 и оно вечное:** на нём висят пути.

**Что такое признак — его же слово, дословно:** «регистр признаков это то что подозревает или о чем
думает собеседник во время того когда он задаёт обращение к памяти или чат боту или любой другой
службе» в формате добавления или извлечения информации. То есть признак — **смысл обращения**, а не
место хранения и не ярлык таблицы.

| Что | Где |
|---|---|
| сами записи | `agi-config.json` — один файл |
| указатель (ключ · название · тип · накопление) | `index.json` — **порождается**, руками не правится |
| словари, проверки, вывод имени рода | `../lib/features.mjs` |
| сторож, стоящий в сборке | `../scripts/check-features.mjs` (`node scripts/check-features.mjs --fix` чинит указатель) |
| наружу | `GET /v1/features` и `GET /v1/features/{ключ}` |
| замысел целиком | `../development-docs/PASSPORT.md` §21 |

## Три закона этой папки

🔒 **`storedIn` ЗДЕСЬ НЕТ И БЫТЬ НЕ МОЖЕТ.** Имя рода выводится **из ключа**: `person.city-where-he-lives-now`
→ род `city_where_he_lives_now`. Значит второй правды о месте не существует в принципе — ей негде
разойтись с первой. Сторож роняет сборку на записи с этим полем.

🔒 **КЛЮЧ ВЕЧЕН.** Форма — `<область>.<фраза-через-дефис>`, фраза по стандарту имён памяти
(`../lib/naming.mjs`): английские слова, путь от человека вниз. Переименование ключа равносильно
потере всего, что под ним записано.

🔒 **ТРОЙКА `tags` · `triggers` · `answers` ОБЯЗАТЕЛЬНА.** По ней признак находят словами человека,
без вызова модели. Запись без неё находит только тот, кто помнит ключ наизусть.

## Один файл, а не файл на запись

Решено измерением соседней службы (157-5): выигрыш даёт **указатель**, а дробление на файл-на-запись
дороже монолита на самом частом вопросе — «что вообще есть». Поэтому здесь монолит плюс порождённый
`index.json`.
