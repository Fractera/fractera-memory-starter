## 1. Что это такое одной мыслью

**Память — чёрный ящик.** Снаружи ей говорят человеческой фразой и человеческой фразой спрашивают.
Куда лечь, заводить ли новое место, рождать ли сущность, звать ли модель — **решает она сама**, и
наружу об этом не рассказывает.

**Слово владельца 2026-09-09:** «это должно выглядеть, как будто мы обращаемся в облако Google —
просто отправляем запрос, получаем результат, а что там происходит, не важно».

🛑 **И ОБРАТНОЕ ТОЖЕ ЕГО СЛОВО:** «ящик не говорит — слушай, я не хочу давать тебе весь ответ, давай
я дам сырые данные, а ты делай с ними что хочешь». **Не смог — предлагает копать глубже и называет
цену, а не сваливает работу наружу.**

## 2. API — что есть СЕГОДНЯ

Адрес: `https://memory.<домен>` (nginx) и `http://127.0.0.1:3700` · замок — ключ памяти `x-memory-key` для чужих
инструментов или секрет машины `x-data-secret` для своих процессов.
🪦 Здесь стояло «только петля · замок — общий секрет машины»: верно до 185 (ключ памяти), устарело молча.

### Живость и договор

| Адрес | Что делает | Замок |
|---|---|---|
| `GET /v1/health` | жива, версия договора, мера качества имён | **открыт** |
| `GET /v1/contract` | сам договор машинно — из него порождаются инструменты агента | закрыт |

🔒 **`health` открыт намеренно:** его зовут установщик и сторож, у которых секрета может не быть, а
сказать «я жива» не значит выдать хоть что-то о человеке.

### Два глагола — всё, что мир умеет делать с памятью

```
POST /v1/remember   { who, text }
POST /v1/recall     { who, text? }
```

**`remember`** — сказать памяти то, что сказал человек, его же фразой.
Возвращает `what_happened` (словами, которые агент произносит человеку), `noted` (что легло),
`dropped` (что не легло и **почему**), `skipped_not_about_him`.

**`recall`** — спросить. **Без вопроса отдаёт всё и не зовёт модель вовсе** — этот путь обязан быть
мгновенным. Возвращает `known` (у каждого значения `claim` и `basis`),
`not_yet_known` (чего не хватает и почему это важно), `used_model`.

🔒 **С ДОГОВОРА 2.6.0–2.7.0 (шаг 200, 2026-09-14):**
- **`remember` принимает вложения внутри себя:** JSON как прежде, либо `multipart/form-data` — часть `payload` с тем же JSON и части `files`;
  параметры `links` (страницы) и `youtube` (ролики) с проверкой рода: ролик в `links` — `link-is-youtube`, не ролик в `youtube` — `youtube-not-youtube`.
  Файлы ложатся путём `keep_object`, ссылки — слоем ссылок; судьба каждого — в `objects`.
- **Ответ обоих глаголов типизирован:** схема `output` в `GET /v1/contract`; обязательны `ok`, `what_happened`, `text` (строка на факт и на
  объект), `objects` (идентификаторы) — у отказов тоже.
- **`recall` с вопросом ищет и объекты по смыслу** (встраивание); фильтра «о ком» пока нет.
- 🛑 **Качество чтения измерено и плохо** (матрица 200-7): русский вопрос не совпадает с английскими именами родов → «вот всё». Стратегия
  замены — шаг 201 «Схема в центре».

🪦 **«ДВА ГЛАГОЛА — ВСЁ» ВЕРНО ДЛЯ ФАКТОВ О ЧЕЛОВЕКЕ И ТОЛЬКО ДЛЯ НИХ.** С 194-15 у памяти есть вещи целиком — объекты,
и у них свои три метода (раздел «Объекты» ниже). Абзац ниже оставлен как закон о фактах.

🔒 **ПОЧЕМУ ИХ ИМЕННО ДВА.** Запись меняет состояние, чтение нет; слить их в один «расскажи памяти
что-нибудь» значило бы потерять и повторяемость, и безопасность. Больше двух наружу не нужно — всё
остальное внутренние решения ящика.

### Объекты — вещь целиком (194-15 … 194-17, договор 2.5.0)

```
POST /v1/keep_object        multipart { file, … }  или  JSON { url, … }
POST /v1/find_objects       { question }
POST /v1/open_object        { id, from? }
GET  /v1/objects/{id}/file  байты с типом и именем
```

**`keep_object`** — положить снимок, голосовое, видео, PDF, Markdown, HTML, код, текст. Описание пишет память
(Claude; звук — whisper-1 с метками времени; видео — дорожка и шесть кадров), если зовущий не прислал своё саммари.
Ложится **в четыре места или ни в одно**: файл с полным описанием — объектное хранилище; саммари — строка
`messages_that_came_into_memory` и карточка поиска; полное описание с происхождением (`source`, `author`, дата) —
документ графа. Путь один у стенда, агента и договора: дверь `object-ingest` → `ingest()` → `keep()`.
**По адресу** память скачивает файл сама (`lib/fractera/fetch-url.ts`): адрес, разрешающийся в петлю, частную сеть,
link-local или адрес машины, — `url-forbidden`; страница `text/html` — `is-a-page`.

**`remember.media`** — список `{url}`: каждое вложение идёт тем же путём, судьба каждого — в `objects` ответа.
Род вложения определяет память (`kindOf`), зовущий его не называет.

**`find_objects`** — по смыслу, одним встраиванием, без хода модели; у каждой находки `messageId`, `kind`,
`title`, `summary`. Поиск через договор не пишет случаи стенда. **`open_object`** — карточка, текст частями,
адрес файла.

Публичный адрес с ключом памяти, хранилища читаются мимо кода памяти.

### 🪦 Каталога таблиц больше нет (206-6)

Здесь стояли два адреса только на чтение — список имён хранилищ и описание одного имени, —
и мера качества имён в `health`: доля обращений за описанием к обращениям за списком.
Память ведёт **одну** таблицу входящих сообщений, и спрашивать её об именах хранилищ стало
не о чем: измерено 2026-09-16, список отдавал пустоту при живом `ok:true`.

🔒 **ЗАПРЕТ, РАДИ КОТОРОГО КАТАЛОГ И СТРОИЛСЯ, ОСТАЛСЯ И СТАЛ СТРОЖЕ:** где искать, решает
память. `recall` берёт человеческую фразу и никогда — имя хранилища.

### Отказы, которые память умеет назвать

| Отказ | Что значит | Чем чинится |
|---|---|---|
| `model-quota-exhausted` | у ключа кончились оплаченные токены | пополнить счёт |
| `model-key-rejected` | ключ отвергнут | заменить ключ |
| `model-key-missing` | ключа нет на машине | положить в склад машины |
| `model-unreachable` | сети нет либо слишком часто | подождать |

🔒 **ДЕНЬГИ И КЛЮЧ — РАЗНЫЕ ОТКАЗЫ.** Один код на оба заставил бы владельца гадать, платить ему или
менять ключ.
🛑 **«РАБОТАЕТ» НЕ РАВНО «ОПЛАЧЕНО»:** `/v1/models` OpenAI отвечает `200` и на пустом счёте — деньги
видны только настоящему вызову.

## 3. Чего память НЕ умеет — названо, чтобы никто не ждал

- **Случай Дениса не работает.** «Кто мог знать президента» и «служба в Кремле» не имеют ни одного
  общего слова; механический поиск найдёт **ноль**. Нужен уровень ② и выше.
- **События** («вчера потратил 40 евро») — не значение, а поток во времени. Другая природа.
- **Факты о третьих лицах** — распознаются и **не хранятся**, но об этом сказано в ответе.
- **Связи между двумя сущностями** («Миша женат на Ане») — полем не выражаются никогда.
- **Понижение формы** — 🛑 опаснее повышения: повышение ничего не теряет, понижение теряет всегда.
- **Страницы по ссылке** — `keep_object` отвергает `text/html`; страницы и YouTube память открывает
  службой ИИ-браузера, а не сама.
- **Удаление объекта через договор** — нет; забывает только стенд.
- **Прерывание сессии агента памяти** — в договоре описываем заранее, но сегодня не реализуем:
  модель одна.

🛑 **ФРАЗА С ДВУМЯ СМЫСЛАМИ ТЕРЯЕТ ОДИН, И ЭТО ИЗМЕРЕНО 2026-09-09.** «Обращайся ко мне на ты»
после «меня зовут Роман» дало ответ «это уже было записано: name he is called — Роман»: модель
сочла фразу тем же фактом об имени, и форма обращения не записалась **молча**.
🔒 Признак дефекта общий: `noted` говорит «уже записано» там, где человек сказал НОВОЕ. Лечение —
не в промпте: надо, чтобы «уже записано» звучало только при совпадении ЗНАЧЕНИЯ, а не рода.

## 4. Как проверять

```
npm run check                        # договор годен: semver, типы только из JSON Schema
npm run probe                        # служба жива и отдельна
node scripts/probe/three-verbs.mjs   # три глагола договора, с негативными контролями
node scripts/probe/api-i18n.mjs      # страница API: у каждого метода и параметра перевод в каждом языке
```

Все приборы лежат в `scripts/probe/` и убирают за собой по своей метке — никогда не целыми таблицами.

🔒 **ОТДЕЛЬНОСТЬ ДОКАЗЫВАЕТСЯ ТОЛЬКО ОСТАНОВКОЙ ПРИЛОЖЕНИЯ БОТА.** Прибор живости говорит это вслух
сам: пока они падают вместе, отдельности нет, как бы аккуратно ни лежали папки.
