## Какие шаги вошли, включая попутные

- **203-1…203-5** — по плану, согласованному формами выбора.
- **204 (попутный)** — появился словом владельца посреди согласования плана 203: «мне нужен предварительный шаг … опиши как работает сейчас
  архитектура». Прошёл пять поправок владельца и стал описанием целевой схемы со сносками и метками навыков.
- **Вливание 201 → 202 → 204 → 203 в `main`** — не планировалось; понадобилось, потому что установщик клонирует `main`.
