# Ссылки в памяти: страница и ролик как объект, источник которого адрес

**Что это.** Память приняла новый род входящего — **ссылку**. Человек даёт адрес, и память сама решает, чем его открыть: обычную страницу
открывает настоящий браузер (служба ИИ-браузера), ролик YouTube читает официальный API. Извлечённое ложится в те же четыре хранилища, что любой
объект, и находится теми же вопросами. Седьмой род мультимодальности на главной `memory.aifa.dev`.

**Где живёт.** Репозиторий `fractera-memory-starter`: `lib/fractera/web.ts` (страница), `lib/fractera/youtube.ts` + `lib/youtube-chapters.mjs`
(ролик и главы), `lib/architect/youtube-key.ts` (ключ), двери `app/api/fractera/link-test`, `link-test/describe`, `link-ingest`, `link-search`,
`youtube-key`, экран `app/[lang]/settings/_components/link-bench.client.tsx`, раздел меню `link-test`, навык `.claude/skills/use-links`.
**Шаги:** 195-1, 195-2, 195-4, 195-5, 195-7 … 195-11, 195-13 — итоги в `completed-steps/`, обзор в `195-main.md`.

## Чего не умеет — прямо
- **Через API ссылку не положить:** метода `keep_links` нет, договор 2.5.1 говорит это в описании `remember.media`. Ссылку кладёт человек на
  стенде «Тест ссылок».
- **Текста субтитров нет:** `captions.download` по ключу → `401` (измерено). Расшифровка — отдельный метод вне памяти; браузерный путь — шаг 198.
- **Режима «сравни» нет** (повторная ссылка по умолчанию возвращает уже лежащее).
- **Порог поиска 0.30 не измерен на ссылках**; имя с ошибкой в транслитерации не находится — правило вошло в навык, не в код.
- **Вес структуры не ограничен:** снимок MDN без текста 57 703 знака.
Всё перечисленное — строками в `development-docs/BACKLOG.md` федерального слоя.

## Решения владельца, без которых шаг был бы другим
«абсолютно одинаковое решение что для объекта что для ссылки» · «любые другие микро сервисы могут обращаться к нему только через API» ·
«Маршрут слоя данных» · «да, делай защиту от 403 и потом оценку» · «Общий + подпись» · «Ключ API (AIza…)» · «только описание и структуру» ·
«не тащить итоговый HTML» · «нужно разрабатывать другой метод… На этом поставим точку в разработке памяти».

## Что этот шаг дал за пределами ссылок
- **Писатель связей между записями** (`linkMessages`): таблица существовала с 194-1 и не вызывалась никем.
- **Полное описание объектов перестало искажаться:** форма превращала `\n` в `\r\n` — дефект жил с 194-4 у всех объектов, вылечен записью
  описания JSON-дверью медиатеки со сверкой байт в байт.
- **`think()` больше не объявляет успешный ход отказом входа**, если ответ модели упоминает `/login` — дефект касался любого вызова модели.
- **Три закона, годных вне памяти:** что положено в снимок, то и станет описанием · отметка оставляет способность живой, «убрать» значит убрать ·
  адрес, названный чужим API, проверяется фактом.
