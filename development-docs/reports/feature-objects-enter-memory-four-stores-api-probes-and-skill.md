# Репорт фичи: объект входит в память — четыре хранилища, договор, приборы, навык

**Шаги:** 192 (объектное хранилище) · 194 (объект входит в память). **Закрыто:** 2026-09-13.
**Где живёт:** `fractera-memory-starter` → `/opt/fractera/memory`, порт 3700, `memory.aifa.dev`.

## Что фича умеет сегодня — и чем доказано
- **Принимает файл любого читаемого рода** — снимок, голосовое, видео, PDF, Markdown, HTML, исходный код, текст — тремя
  путями: стенд (описать → поправить → сохранить), договор `POST /v1/keep_object` (форма или `url`), вложения
  `remember.media`. → прибор `object-describe.mjs`: четыре рода через договор `✓ OK`.
- **Описывает сам:** Claude по подписке читает картинки, PDF, страницы и код (код — анализ, не пересказ, не исполняется);
  whisper-1 расшифровывает звук с метками времени; видео — дорожка и 6 кадров на одной шкале. → 17 меток у видео и звука.
- **Кладёт в четыре места или ни в одно:** файл с полным описанием — объектное хранилище; саммари — строка
  `messages_that_came_into_memory` и карточка поиска; полное описание с происхождением (источник, автор, дата) — граф.
  Сорвалась ступень — положенное снимается, строка остаётся `failed`. → `object-four-stores.mjs`, `v1-objects.mjs`.
- **Не пускает чужого внутрь машины:** адреса петли, частных сетей, link-local и самой машины — `url-forbidden`, проверка
  на каждом перенаправлении; страница — не файл (`is-a-page`). → пять запрещённых адресов `400`.
- **Находится и отдаётся снаружи:** `find_objects` по смыслу без хода модели, с номером строки и родом; `open_object`
  частями; `GET /v1/objects/{id}/file` байт в байт. → `sha256` совпал.
- **Видно человеку:** стенд объектов с просмотрщиками всех родов, вкладка «Навык» у каждого стенда, страница API en/ru,
  главная memory.aifa.dev по коду.
- **Приборы не оставляют следов в живой памяти:** состав базы до = после (5 строк, 43 файла, 38 карточек, 5 документов).

## Какие шаги вошли, включая попутные
- **192** — хранилище, двери, руки агента `find_objects`/`open_object`/`keep_object`, навык `use-object-store`.
- **194-1…194-6, 194-13** — план шага: таблица, описание, сохранение, граф с происхождением.
- **Попутные внутри 194, пришедшие словом владельца посреди шага:** 194-8 (просмотрщики — «скопировать и адаптировать»),
  194-9 (поиск как загрузка), 194-10 (код и форматы), 194-11/12 (главная и оглавление), 194-14 (навык под API),
  194-15…194-18 (договор — после сверки API, где `media` молча выбрасывалось), 194-19 (вкладки навыков).
  Цена фичи поэтому выше плана: 7 подшагов плана выросли в 19.

## Чего фича НЕ умеет — долги
- PDF описывается до 286 с при пределе хода Claude 300 с — длинный PDF может отказать по времени.
- Забытая временная папка описания на сервере; причина не найдена.
- Удаление объекта через договор; страницы по ссылке и YouTube (ждут службу ИИ-браузера — шаги 196, 195).
- Факты о человеке из содержимого файла не извлекаются в таблицы памяти.
- Навык `describe-incoming-object` не подключён к Telegram-службе: там свой агент.
