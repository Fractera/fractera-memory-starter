## Что надо построить

**Служба перестаёт звать OpenAI и запускает агента Claude Code в своей папке.**

Известное на входе:
- ключа Anthropic на машине **нет** (`/etc/fractera/secrets.env` — проверено);
- Claude Code **авторизован подпиской**: `/root/.claude/.credentials.json`;
- 🛑 **не проверено, запускается ли `claude -p` неинтерактивно** — первый пробник за 60 с ничего не
  вернул. Это первое, что надо измерить.

Порядок: измерить запуск → заменить вызов в `remember` → замерить время → показать владельцу.
