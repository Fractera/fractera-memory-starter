## 🛑 Открытые решения владельца — без них 189-6 не начинать

**1. Судья между графом и ответом.** Испытание показало (см. ниже): граф **всегда** возвращает
ближайшее и пустого ответа не знает. Значит третий уровень, отдающий контекст как есть, будет
уверенно отвечать неверно. Два пути: **порог близости** (дёшево, грубо) или **ход модели**, которая
скажет «это не про то» (дорого, точно). Решает владелец.

**2. Изоляция корпусов.** Вопрос из второго испытания притянул сущность из первого: у графа один
общий склад. Для стенда терпимо, для продукта — нет.
