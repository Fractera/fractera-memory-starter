## 3. Известные ограничения
- 🛑 Подагенты запрещены; Skill Creator — только правила письма, без прогонов.
- 🔒 Ключ памяти в браузер не уезжает никогда (закон 185): проводит дверь стенда на сервере.
- 🔒 `remember`, `recall` на глубине, описание объекта (`keep_object`) тратят ходы модели из квоты подписки, общей с ботом — прибор называет цену.
- 🛑 `forget_journal` стирает журнал памяти ЦЕЛИКОМ, живой журнал владельца — в приборе и на экране только с подтверждением; прогон — по его слову.
- 🛑 Запись прибора в живую память убирается по метке; способ уборки строк `remember` — измерить до прибора (200-5).
- 🔒 Доставка перезапускает службу — предупреждать до доставки.
- 🔒 Остальные стенды (граф, вектор, объекты, ссылки) не трогаются.
