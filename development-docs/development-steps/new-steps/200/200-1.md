# 200-1 — дверь стенда ходит только в публичный `/v1/*`

## 1. Что строится
- `app/api/fractera/memory-test/route.ts` — вместо прямого вызова `lib/verbs.mjs`: запрос в `https://<публичный адрес памяти>/v1/<метод>`
  (адрес — из хоста запроса, как у страницы API) с `x-memory-key` из `lib/api-key.mjs`; `GET` для каталога (`tables`, `tables/{имя}`, `health`,
  `contract`, `objects/{id}/file`); замок стенда — сессия `architect`.
- Ответ экрану: `{ request: { method, url, headers (ключ скрыт), body }, status, ms, response (сырое тело целиком) }`.
- Прямые импорты исполнителей из двери удаляются.

## 2. Что считается готовым
Каждый вызов стенда проходит путь внешней программы: nginx → `server.mjs` → замок ключа → проверка обязательных → исполнитель.

## 3. Чем доказывается
- **A:** прибор зовёт дверь стенда `people`, `contract`, `tables`; в журнале nginx на тот же момент — строки `GET/POST /v1/…` с адреса сервера;
  в коде двери импортов `lib/verbs.mjs` 0.
- **B (негатив):** `remember` без `text` → ответ несёт `missing-params` ДОГОВОРА (раньше приходил отказ исполнителя); ключ памяти в ответе
  двери и в собранных чанках — 0; без сессии — 401.

## 4. На что опирается
Договор 2.5.1.

## 5. Чего не входит
Экран (200-2), вложения (200-3).
