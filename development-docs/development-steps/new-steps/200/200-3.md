# 200-3 — вложения по-настоящему: файл и адрес для `keep_object`, адреса для `remember.media`

## 1. Что строится
- Параметр типа `binary` (`keep_object.file`) — выбор файла; дверь стенда шлёт в `/v1/keep_object` `multipart/form-data` потоком, как внешняя программа.
- `keep_object.url` — поле адреса, тело JSON.
- `remember.media` — список адресов `{url}`; ответ показывает судьбу каждого вложения (`objects`).
- Ряд из пяти отключённых кнопок «Загрузка» и метка «не доезжает» удаляются; слова — вместе с ними.

## 2. Что считается готовым
С экрана стенда через публичный API кладётся объект файлом и адресом, а фраза с вложениями возвращает судьбу каждого.

## 3. Чем доказывается
- **A:** прибор через дверь стенда: `keep_object` файлом (Markdown) и адресом → `messageId`; `remember` с `media` → `objects` по каждому; уборка по метке.
- **B (негатив):** адрес страницы в `keep_object.url` → `is-a-page`; файл неподдерживаемого рода → `describe-kind-unsupported`; в сборке отключённых
  кнопок загрузки 0.

## 4. На что опирается
200-1, 200-2.

## 5. Чего не входит
Ссылки как род (`keep_links` — в `BACKLOG`).
