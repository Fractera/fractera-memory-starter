# 200-5 — вложения внутри «Сказать»: адреса `media`, судьба каждого в ответе

## 1. Что строится
- Орган «Вложения» в расширенных параметрах `memory-test-controls.client.tsx`: список адресов, строка на файл, «добавить / убрать»; метка
  «доезжает» — из договора (`remember.media`).
- `lib/bench-call.mjs`: непустые адреса → `media: [{url}]` у «Сказать»; у «Спросить» — «не доезжает».
- Под ответом «Сказать» — судьба каждого вложения из `objects` ответа памяти (id объекта и `messageId` либо отказ с причиной).
- Слова `en`/`ru` органа.
- По развилке 2 «файл с диска» — **не здесь**: это расширение договора, отдельный шаг.

## 2. Что считается готовым
Со стенда «Сказать» с адресом файла кладёт вложение через `/v1/remember`, и экран показывает, что с ним стало.

## 3. Чем доказывается
- **A (поверхность владельца + ответ памяти):** в Chrome владельца «Сказать» с фразой без фактов и адресом небольшого публичного
  Markdown-файла → ответ `objects[0]` с id и `messageId`; экран показывает их. Цена названа до: разбор фразы + описание вложения моделью.
- **B (негатив):** адрес HTML-страницы → в `objects` отказ `is-a-page`; адрес в петлю `http://127.0.0.1/` → `url-forbidden`.
  Уборка: `forget(ids)` через дверь стенда объектов; остаток (документ графа, строка сообщения) назван в итоге.

## 4. На что опирается
200-4.

## 5. Чего не входит
Файл с диска в «Сказать» (изменение договора); методы объектов наружу.
