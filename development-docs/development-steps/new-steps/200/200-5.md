# 200-5 — «Сказать» принимает вложения: файлы по родам памяти, обычная ссылка и ссылка YouTube

## Откуда
Владелец 2026-09-14: «мы разработали определённый виды вложений это просто перечислять такой же количество кнопок кнопку загрузить аудио
кнопку загрузить видео кнопка загрузить и так далее и отдельно рассылки обычная ссылка YouTube ссылка сделай валидацию если в обычную ссылку
ставит ссылку от YouTube а в YouTube ставит обычную ссылку чтобы ты не проходила».

## 1. Что строится
- **Договор 2.6.0 (MINOR), `remember`:**
  - тело `multipart/form-data` принимается наравне с JSON: поля фразы и параметров — частями формы, файлы — частями `files`;
  - новые необязательные параметры `links` (обычные страницы) и `youtube` (ролики) — списки адресов;
  - новые отказы с причиной у каждого вложения: `link-is-youtube` (ролик в поле страницы), `youtube-not-youtube` (не ролик в поле YouTube);
  - прежний `media` (адреса файлов) работает как был.
- **`server.mjs`:** `POST /v1/remember` с `multipart/form-data` идёт потоком во внутреннюю дверь (приём `passToDoor`, как у `keep_object`), JSON — прежней веткой.
- **Внутренняя дверь** `app/api/fractera/remember-ingest/route.ts`: каждый файл → `keep()` (тот же путь, что `object-ingest`);
  `links` → путь двери `link-ingest`; `youtube` → путь `link-test/describe` (`readVideo`); проверка рода — `youtubeId()`; затем `remember`
  с фразой и параметрами; `objects` — судьба каждого вложения (id объекта, `messageId`, род) или отказ.
- **`next.config.ts`:** `experimental.proxyClientMaxBodySize: "200mb"` — Next по умолчанию молча обрезает тело на 10 МБ.
- **Стенд, «Сказать» → расширенные параметры → «Вложения»:** кнопка загрузки на каждый род из `kindOf()` (Аудио · Видео · Изображение · PDF ·
  Документ Markdown/HTML/текст · Код) — порождаются из списка родов с фильтром расширений; поле «Обычная ссылка» и поле «Ссылка YouTube»
  с проверкой рода на экране (тем же `youtubeId()`); выбранное видно списком с «убрать». Файл выбран — дверь стенда шлёт форму потоком.
- **Под ответом** — судьба каждого вложения.
- Слова `en`/`ru` органа.

## 2. Что считается готовым
Со стенда «Сказать» с файлом, обычной ссылкой и ссылкой YouTube кладёт все три через `/v1/remember`, и ответ называет идентификатор
объекта каждого; ссылка чужого рода отвергается и на экране, и в API.

## 3. Чем доказывается
- **A (поверхность владельца + ответ памяти):** в Chrome владельца «Сказать» с фразой без фактов, небольшим Markdown-файлом, адресом
  страницы-эталона (MDN) и роликом YouTube → `objects` из трёх записей с id и `messageId`; журнал nginx — `POST /v1/remember` с адреса сервера.
  Цена названа до: разбор фразы + три описания моделью.
- **B (негатив, две плоскости):** ① API: ролик в `links` → `link-is-youtube`, страница в `youtube` → `youtube-not-youtube`, запись не создана;
  ② экран: та же подмена — кнопка «Отправить» не проходит, строка «не тот род ссылки». Уборка: `forget(ids)`; остаток (документ графа,
  строка сообщения) назван в итоге.
