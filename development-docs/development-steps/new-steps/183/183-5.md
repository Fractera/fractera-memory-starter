# 183-5 — цепочка размышлений возвращается по требованию зовущего

## 1. Что строится — файлы и параметры поимённо

| Файл | Что с ним делаем |
|---|---|
| `contract.mjs` | у `recall` необязательное `want_chain` (да · нет), по умолчанию **нет** |
| `lib/verbs.mjs` | при `want_chain: true` в ответе появляется `chain` — шаги поиска, которые память прошла; при `false` поля нет вовсе |
| `app/[lang]/settings/_components/memory-test-controls.client.tsx` | переключатель «возвращать цепочку размышлений» |

🔒 **Умолчание — «нет», и это решение паспорта §6:** рекурсивное размышление порождает много текста,
и переполнять свой контекст или нет решает тот, кто спросил. Умолчание «да» тратило бы контекст
каждого зовущего без его ведома.

🔒 **Выключено значит «поля нет», а не «поле пустое».** Пустое поле читается как «память не думала»,
и это то самое уверенное умолчание, которое дороже отсутствующего значения.

## 2. Что считается готовым

Один и тот же вопрос с включённым переключателем возвращает `chain`, с выключенным — ответ без
этого поля.

## 3. Чем доказывается — две плоскости, названные заранее

**Плоскость первая — прибор на паре ответов (машинная).**
`scripts/probe/chain.mjs`: `want_chain: true` даёт непустой `chain`.
🔒 **Негативный контроль здесь и есть вторая половина замера:** `want_chain: false` обязан дать
ответ, где ключа `chain` **нет** — проверяется наличием ключа, а не его пустотой.

**Плоскость вторая — живой стенд в браузере (человеческая).**
Два ответа подряд в правой колонке: в одном видна цепочка шагов поиска, в другом её нет, а
панель «что уедет» показывает разницу в теле запроса.

## 4. На что опирается

183-2 — договор вырос, порядок правки обкатан.

## 5. Чего в подшаг не входит

- **рекурсивное размышление само по себе** (уровень 5) — цепочка описывает те шаги, которые память
  действительно проходит сегодня;
- цепочка у `remember`: запись рассказывает о себе полем `what_happened`, второго рассказа ей не
  нужно;
- хранение цепочек между вызовами.
