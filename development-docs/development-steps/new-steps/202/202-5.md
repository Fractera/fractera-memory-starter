# 202-5 — «Шаги разработки»: новые и завершённые

## 1. Что строится
- `lib/build-docs.mjs` — перечисление шагов: `new-steps/` (папки `<N>/` и файлы `<N>-*.md`) и `completed-steps/` (файлы `<N>-<k>.md` группой
  по номеру); название — первый заголовок `<N>-main.md` либо первого файла; **сортировка по номеру убыванием** — новые сверху.
- Меню: «Шаги разработки» → «Новые шаги» · «Завершённые шаги» → список шагов открытого подраздела (два уровня вложенности; закрыты, пока раздел
  не выбран). Клик по шагу — модальное окно со всеми файлами шага (главный первым, подшаги по порядку).
- Правая колонка: роль новых шагов (план с ТЗ, согласуется до кода) и завершённых (итог с хэшем коммита и доказательствами).

## 2. Что считается готовым
Оба подраздела показывают все шаги сверху новые; любой шаг открывается целиком в модальном окне.

## 3. Чем доказывается
- **A (HTML):** в «Завершённых» первый пункт — наибольший номер, последний — наименьший; окно шага содержит текст его главного файла.
- **B (негатив):** номер шага не из списка (`?doc=step-done:999999`) окна не открывает; порядок в меню совпадает с порядком номеров на диске.
