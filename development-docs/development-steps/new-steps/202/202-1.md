# 202-1 — раскладка мастерской и главное описание

## 1. Что строится
- `app/[lang]/build/page.tsx` — страница в раскладке `WorkspaceShell` (как `settings`): крошки, шапка, **блок-цитата** о стартовом шаблоне,
  карточка «Как поделиться решением» (форк → ветка → pull request, обсуждение в issues, лицензия стартера), левое меню шести пунктов,
  правая колонка по `?section=`.
- `app/[lang]/build/_lib/build-sections.ts` — единственный источник порядка разделов: `terminal · task · current · steps · skills ·
  instruction` плюс подразделы `steps-new · steps-done`.
- Словарь `build.i18n.ts` — ru и en; красная врезка о риске переезжает внутрь раздела «Терминал».
- Замок: содержимое мастерской — только архитектору (как терминал сегодня).

## 2. Что считается готовым
`/ru/build` и `/en/build` показывают стандартную двухколоночную раскладку с шестью пунктами и цитатой; каждый пункт открывает свой раздел.

## 3. Чем доказывается
- **A (отданный HTML с сессией архитектора — счётом):** `data-workspace` = 1, пунктов меню ≥ 6, `<blockquote` = 1 с текстом о шаблоне.
- **B (негатив):** `?section=нет-такого` падает на терминал, а не на пустую колонку; без сессии содержимое мастерской не отдаётся.
