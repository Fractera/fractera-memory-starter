# 205-2 — три новых признака; возраст помечен долгом

## 1. Что строится
- `AGI-CONFIG/agi-config.json`: `person.tasks-he-plans-to-do` (object, list, глубина 1: что, срок, состояние) ·
  `person.places-he-marked` (object, list, глубина 1: название, место, координаты; охват `place`) · `person.ideas-he-had` (text, list) —
  с `tags`, `triggers`, `answers`, `howToFind`, `onMissing`, `example` из переписи (`entity.task`, `entity.place`, `entity.idea` чата).
- `person.age-he-is-now`: поле `retired` с причиной (§21.2 — год рождения); разбор перестаёт предлагать его кандидатом; живые значения не
  трогаются.

## 2. Что считается готовым
Фраза «надо позвонить в банк насчёт карты» через `/v1/remember` ложится строкой задачи; каталог отдаёт 23 действующих признака.

## 3. Чем доказывается (названо заранее)
- **Плоскость 1 — каталог:** `GET /v1/features` → 23 действующих и 1 снятый; **негатив** — снятый возраст не попадает в кандидаты разбора
  (прибор индекса кандидатов по фразе «мне 40 лет» — ключа возраста в списке 0).
- **Плоскость 2 — живая запись с меткой прибора** (квота названа до прогона; уборка только своей записи): `remember` → в ответе признак
  `person.tasks-he-plans-to-do` принят, в таблице одна строка с меткой; **негатив** — фраза без задачи («спасибо») строки задачи не рождает.

## 4. На что опирается
205-1 (форма записи).

## 5. Чего в подшаг не входит
Жизненный цикл задачи со сменой состояния по времени и напоминания (служба чата) · перенос возраста в дату.
