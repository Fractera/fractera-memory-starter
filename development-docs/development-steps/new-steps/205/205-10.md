# 205-10 — реестр догоняет хранилище: признаки для 27 родов живой памяти

## Откуда взялась задача

Найдено прибором 2026-09-15 при доставке 205-1: «живых родов 46, покрыто признаками 19». Ответ владельца на форму: **«Добавить сверку в 205
(Recommended)»**. Затем правила 205-4, дословно в `205-main.md` §5 и паспорте §23: модель продолжает заводить колонки и таблицы сама
(«позволяет работать с базами данных минуя граф»); **признак заводит агент разработки шагом**; дубль **помечается снятым с заменой**.
🪦 Первая редакция этого ТЗ предлагала «закрыть путь мимо реестра» и переносить 12 родов в граф — **отменена ответом владельца на правило 1**.

## 1. Что строится

- **Счёт без значений (только чтение):** прибор `scripts/probe/kinds-count-205-10.mjs` на сервере через слой данных с секретом машины —
  по каждому из 46 родов: у скольких людей есть значение, есть ли таблица рода и сколько в ней строк. Значения не печатаются. Прибор не
  зовёт двери с `rowOf` (205-3: чтение там заводит строку человека). Итог предъявляется владельцу.
- **Признаки для 27 родов** (перепись §9, по форме 205-1) в `AGI-CONFIG/agi-config.json`; ключ выводится из рода
  (`person.<род-через-дефис>`), чтобы признак и живой род совпали без переноса:
  - **21 род → действующий признак** — с `tags`, `triggers`, `answers`, `howToFind`, `onMissing`, `example`, `skills`;
  - **6 родов → признак, снятый с заменой** (`retired`): 2 прямых дубля (траты, валюта), «когда перестаёт отвечать» → рабочие часы,
    «планы на месяц» → задачи, 2 рода глубины 2 (друг Денис, собака) → граф по §21.2.
- **Значения не переносятся и не удаляются** — перенос только отдельным словом владельца после счёта.

## 2. Что считается готовым

Прибор 201-3 на сервере печатает «живых родов покрыто признаками» без непокрытых.

## 3. Чем доказывается (названо заранее)

- **Плоскость 1 — сторож и прибор на сервере:** `check-features.mjs` — 0 нарушений на 51 записи (24 + 27); прибор 201-3 «НЕ ПОКРЫТО» — 0.
  **Негатив:** до правки тот же прибор печатает 27 непокрытых (снято 2026-09-15).
- **Плоскость 2 — живая дверь каталога:** `GET /v1/features` → действующих 44, снятых 7; `GET /v1/features/person.currency-he-counts-his-money-in`
  отдаёт `retired` с заменой `person.currency-he-counts-money-in`; **негатив** — ключ, которого нет ни в реестре, ни в хранилище, → 404.

## 4. На что опирается

205-1 (форма записи) · 205-2 (`retired`) · 205-4 (правила, паспорт §23) · **слово владельца по счёту значений и по списку признаков**.

## 5. Чего в подшаг не входит

Перенос и удаление значений · удаление колонок и таблиц · сверка нового рода с кандидатами до его рождения (сноска *⁴, §23.2) · роды,
которые модель заведёт после сверки (их догоняет следующий шаг агента разработки — это и есть правило 2).
