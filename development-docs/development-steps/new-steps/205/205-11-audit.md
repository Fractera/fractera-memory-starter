## 5. Что из этого следует для нового паспорта

1. **Форму берём у `BLACKBOX-API.md` и у сносок README:** построенное и замысел разделены явно,
   замысел — звёздочкой со сноской.
2. **Ни одно утверждение о поиске по радиусу, эволюции навыков, мемоизации, пяти уровнях и сборке
   отчёта-артефакта не переносится как построенное** — только как замысел со сноской.
3. **Раздел «Устройство» `LAWS.md` в паспорт не переносится**, а пишется заново по коду; сам `LAWS.md`
   после этого обязан потерять этот раздел, иначе две правды.
4. **Долг вне 205-11, назван владельцу:** README и главная обещают непостроенное на публичной
   поверхности (радиус, эволюция, мемоизация). Правка публичных текстов — отдельное решение владельца.
