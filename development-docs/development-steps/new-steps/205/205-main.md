## 3. Черновой порядок (развернуть после утверждения переписи)

1. Перепись 70 элементов с решением: признак реестра памяти · механизм памяти вне реестра · снять.
2. Полная форма записи реестра памяти: по названию ясно, что делать (куда кладу, что при отсутствии, охват, навык, потребители).
3. Правила переиспользования и заведения признаков — обсуждение, затем паспорт.
4. Переиспользование элементов реестра из административной панели: любой элемент подключается и берёт свои признаки (предложение владельца).
5. Вкладка в чате читает реестр памяти через договор.
6. Метки навыков у каждого признака.
