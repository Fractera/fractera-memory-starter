# 195-2 — «Получить описание» и «Сохранить в память» по ссылке: полное описание, саммари, четыре хранилища

## Откуда уточнение
Владелец 2026-09-14, приняв 195-1, дословно: «Теперь нужно решить вопрос сохранения результата поиска по ссылке и извлечение. То что
ты представил в виде аккордеона выглядит хорошо но при нажатии на кнопку сохранить всё-таки в полный текст уйдёт объект, в Самаре
уйдёт в Самаре. И так как контента много показывай максимум 1000 пикселей высоту окно с вертикальной прокруткой.»
Решения паспорта §20.6: ссылка — тот же объект, источник — ссылка; повторная ссылка по умолчанию — «ничего не делаем, возвращаем то,
что уже есть»; объём по умолчанию — текст, структура, медиа по атрибутам, весь итоговый HTML — если человек настаивает.
**Я предполагаю, что:** «в полный текст уйдёт объект» — поле «Полное описание» (как у стенда объектов) уходит с объектом в объектное
хранилище, «Саммари» — в саммари строки и карточку; «окно 1000 пикселей» — раскрывающиеся окна содержимого и полное описание блока
«что легло в память».

## 1. Что строится
- `lib/messages.mjs` — род `web` в `KINDS` (форма пересобирается без потерь приёмом 194-10; в живой таблице 5 строк — объявлено до
  доставки); `url TEXT` в `LATE_COLUMNS` и `WRITABLE`; `getSavedByUrl(url)` — последняя строка `saved` с этим адресом.
- `lib/describe.mjs` — `describe({ …, kind: "web", url })`: снимок читается как страница, инструкция модели — назначение, устройство,
  содержание, интерактивное, медиа; адрес назван модели.
- `lib/fractera/web.ts` — `snapshotOf(result, { html })`: Markdown-снимок извлечённого (адрес, итоговый адрес, код, заголовок, мета,
  заголовки, весь текст, ссылки, кнопки, формы, поля, медиа, отвергнутое; итоговый HTML — только с `html: true`).
- `lib/fractera/objects.ts` — `keep({ …, kind?, url? })`: род и адрес ложатся в строку; в происхождении графа — «страница «адрес»»
  вместо «файл».
- Двери (замок `benchGuard`, имена в `proxy.ts`):
  - `app/api/fractera/link-test/describe/route.ts` — `{url, html}`: уже сохранена → `{existing: messageId}` без модели; иначе браузер
    читает страницу целиком (экран держит начало) → снимок → описание → `{title, full, summary, tags, anchors, snapshot, …}`;
  - `app/api/fractera/link-ingest/route.ts` — снимок, поля, `url`: повторно проверяет «уже сохранена» → `keep({kind:"web", url})`.
- `link-bench.client.tsx` — у каждой открытой ссылки: отметка «сохранить итоговый HTML целиком», «Получить описание» (счётчик
  секунд), поля «Полное описание» и «Саммари» (правятся человеком), «Сохранить в память», затем общий блок «что легло в память»
  (`SavedView` стенда объектов, экспортируется; не своя вёрстка); уже сохранённая ссылка — тот же блок и строка словами. Окна
  содержимого — `max-h-[1000px]` с вертикальной прокруткой.
- Слова `en`/`ru` в `memory.i18n.ts`.

## 2. Что считается готовым
Ссылка со стенда лежит во всех четырёх хранилищах: строка `kind=web` с `url`, файл снимка с полным описанием, карточка вектора,
документ графа с адресом и происхождением; повторная ссылка возвращает уже лежащее без хода модели.

## 3. Чем доказывается — названо заранее
- **A (прибор через публичный адрес, `scripts/probe/link-four-stores.mjs`):** `https://example.com/` — описание 200; сохранение 200;
  строка `kind=web`, `url` = адрес, `status=saved`; из строки — файл снимка и полное описание; карточка вектора; документ графа
  `processed`, граф отвечает по уникальному слову, в ответе адрес и происхождение; повтор описания той же ссылки → `existing` без
  модели (быстрее секунды); уборка по метке прибора.
- **B (негатив):** `http://127.0.0.1:3300/` — описание отказывает кодом браузера, записи нет; пустые якоря → граф отказывает, откат,
  строка `failed`, файла и карточки нет; состав таблицы до пересборки = после (5 строк владельца на месте).
  **Глазами владельца** — `memory.aifa.dev/ru/settings?section=link-test`.
