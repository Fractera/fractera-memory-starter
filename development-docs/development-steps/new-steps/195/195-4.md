# 195-4 — YouTube по ссылке: ролик ложится с расшифровкой по минутам или с честной причиной

## 1. Что строится
- `lib/fractera/web.ts` — адрес ролика узнаётся (`youtube.com/watch`, `youtu.be`, `/shorts/`, `/embed/`) и идёт в
  `POST http://127.0.0.1:3800/v1/youtube`; данные ролика и расшифровка строками `[мм:сс–мм:сс]` уходят в описание модели и в
  снимок; нет расшифровки — ролик ложится данными с причиной словами (слово владельца 2026-09-13 «что досталось + причина»).
- Стенд ссылок показывает у ролика дорожки, язык расшифровки, первые строки с метками или причину.

## 2. Что считается готовым
Вопрос «на какой минуте говорится о …» к памяти находит ролик и отвечает меткой времени из расшифровки.

## 3. Чем доказывается — названо заранее
- **A (прибор):** эталонный ролик с субтитрами ложится; в полном описании есть метки `[мм:сс–`; поиск по фразе из середины
  ролика находит объект, а текст объекта содержит метку этой фразы.
- **B (негатив):** ролик с проверкой на ботов (`youtube-bot-check`) — ложится данными без расшифровки, причина названа, не «успех
  с пустым текстом»; несуществующий ролик — отказ, ничего не записано.

## 4. На что опирается
195-3; **федеральный шаг 198** (панель расшифровки, проход проверки на ботов, выбор владельца «Панель расшифровки»). Без 198 подшаг
выполним только в виде «что досталось + причина» — это называется владельцу до начала.

## 5. Чего не входит
Сам обход проверки YouTube и панель расшифровки — это 198.
