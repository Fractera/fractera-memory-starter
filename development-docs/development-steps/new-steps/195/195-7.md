# 195-7 — память зовёт ИИ-браузер через «одну дверь» слоя данных: `/service/ai-browser/*`

## Откуда взялась задача
Владелец 2026-09-14, посреди 195-1, дословно: «по задумке мы создали каждый субдомен и микро service с концепцией того что он имеет
внутри себя API а это значит что любые другие микро сервисы могут обращаться к нему только через API хочу быть уверен что ты не
используешь напрямую архитектуру браузера а используешь егосубдомен и его API?» Измерено: внутренностей браузера память не трогает,
зовёт договор `/v1/read`, но по петле `127.0.0.1:3800`; в «одной двери» слоя данных ИИ-браузера нет. На выбор «Петля + секрет /
Публичный субдомен + ключ / Маршрут слоя данных» — **«Маршрут слоя данных»**.
Маршрутизация: исход A — та же способность шага 195 (память читает ссылки), меняет путь непринятого 195-1.

## 1. Что строится
- `ai-workspace/services/data/server.js`:
  - `INTERNAL["ai-browser"] = process.env.AI_BROWSER_URL ?? 'http://127.0.0.1:3800'`;
  - маршрут `app.all(/^\/service\/ai-browser(\/.*)?$/, requireAuth, …)` — секрет машины браузеру подставляет слой данных сам (входящие
    заголовки прокси не переносит);
  - образец хвоста `^\/service\/[a-z-]+` вместо `[a-z]+`: без дефиса хвост стал бы `-browser/v1/read`; для `rag`/`geo`/`channels`
    образцы равнозначны;
  - предел ожидания параметром `proxy(…, timeoutMs)`, по умолчанию прежние 120 с; у ИИ-браузера — 600 с (до 10 страниц по очереди
    плюс самолечение движка).
- `fractera-memory-starter/lib/fractera/web.ts` — `readLinks` зовёт `dataService().url + "/service/ai-browser/v1/read"` с тем же
  ключом, что у слоя данных (`lib/fractera/data-service.ts`); адреса `3800` в коде памяти нет.
- Документы: `ARCHITECTURE.md` §0 «Одна дверь» и §3.6б, федеральный `CLAUDE.md` (раздел ИИ-браузера), паспорт памяти §20.

## 2. Что считается готовым
Стенд ссылок и прибор 195-1 дают тот же результат, а память ходит в браузер только через `localhost:3300/service/ai-browser`.

## 3. Чем доказывается — названо заранее
- **A:** прибор `scripts/probe/link-test.mjs` через публичный адрес памяти снова `✓ OK` (MDN, TodoMVC, негативы, счёт до = после);
  `grep 3800` по `lib/` и `app/` памяти — 0; прямой вызов `POST 127.0.0.1:3300/service/ai-browser/v1/read` с секретом машины
  возвращает `results`.
- **B (негатив):** `/service/ai-browser/v1/read` без секрета — `401` слоя данных; `/service/rag` и `/service/geo` отвечают как до
  правки (образец хвоста не сломал соседей); `DEPLOYED_COMMIT` слоя данных = отправленный коммит, порт 3300 держит потомок pm2.

## 4. На что опирается
195-1 (стенд ссылок построен), федеральный 196 (служба ИИ-браузера).

## 5. Чего не входит
Публичный субдомен и ключ `fab_…` для памяти (отвергнуто выбором владельца) · запись ссылок в хранилища (195-2).
