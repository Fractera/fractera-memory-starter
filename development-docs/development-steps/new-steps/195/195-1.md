  правится вместе с массивом (девять → десять).
- `app/[lang]/settings/_lib/test-tabs.ts` — `"link-test"` в `TEST_SECTIONS`: четыре вкладки (Загрузка · Поиск · Оценка · Навык)
  приходят сами через `tabsOf`.
- `app/[lang]/settings/_lib/stand-skills.ts` — `"link-test": []` до навыка 195-5.
- `app/[lang]/settings/_i18n/memory.i18n.ts` — `pages["link-test"]`, `testBench.link` (лиды четырёх вкладок), `linkBench` —
  слова перенесены из `readTest` словаря ИИ-браузера (`browser.i18n.ts`) en/ru и адаптированы.
- `app/[lang]/settings/_components/link-bench.client.tsx` — копия `read-test.client.tsx` ИИ-браузера: поле «по ссылке в строке»
  (1–10), кнопка, по каждой ссылке карточка (итоговый адрес и код, заголовок, `load_reached`, счётчики, раскрытие текста, HTML,
  мета, списков элементов и отвергнутого; отказ — код и причина).

  машины); зовёт `lib/fractera/web.ts`; экрану отдаёт начало текста и HTML (20 000 знаков) и длины целиком.
- `lib/fractera/web.ts` — `readLinks(urls, base?)`: `POST <AI_BROWSER_URL | http://127.0.0.1:3800>/v1/read` с `x-data-secret`;
  ответ читается целиком; браузер недоступен — названный отказ `browser-unreachable` (502), не падение.
- `proxy.ts` — имя двери `link-test` в `SELF_GUARDED`.
- `app/[lang]/settings/page.tsx` — лид раздела, «Загрузка» рисует стенд ссылок; «Поиск», «Оценка», «Навык» у `link-test` —
  строка `testBench.soon` (построенное показываем, непостроенное называем).

## 2. Что считается готовым
В левом меню памяти под «Тестом объектного хранилища» есть «Тест ссылок» с четырьмя вкладками; вставив адреса, архитектор видит по
каждому извлечённое браузером; в хранилища памяти ничего не пишется.

## 3. Чем доказывается — названо заранее
- **A (дверь по петле на сервере):** `POST /api/fractera/link-test` с секретом машины на MDN и TodoMVC — по каждой ссылке заголовок,
  текст > 0, у TodoMVC поле ввода; в собранной странице раздел `link-test` есть (`grep` собранных чанков, ложная строка 0).
- **B (негатив):** без сессии и секрета — 401 JSON, не 307; `http://127.0.0.1:3300/` — `url-forbidden` от браузера; браузер
  недоступен (`readLinks` на пустой порт прибором) — `browser-unreachable`; счётчики таблицы и вектора памяти до = после.
  **Глазами владельца** — `memory.aifa.dev/ru/settings?section=link-test`.
