## 3. Известные ограничения, названные до плана

- Цена расширения на страницу — ~110 с и ~14 ходов из квоты подписки, общей с ботом; ИИ-браузер — 7 с и 0 ходов.
- Работает только при включённых компьютере и Chrome владельца; служебный процесс расширения засыпает в долгих сессиях («service worker can go
  idle… breaks the connection»); вкладки видны на экране владельца; страницы открываются с его входами.
- 🛑 Не измерено: спросит ли расширение разрешение на НОВОМ домене; поведение при странице входа или капче («pauses and asks you to handle it
  manually») у службы без человека — вероятное зависание (закон 115: модальный вопрос у процесса без терминала).
- Форма данных: `get_page_text` — текст; заголовки, ссылки, формы, поля и медиа по атрибутам, как у `/v1/read`, — ценой дополнительных ходов.
- Клиентский сервер: у каждого клиента свой Chrome и свой вход в claude.ai; у сервера, вошедшего не через `/login`, пути нет.
