# 194-19 — вкладка «Навык» у каждого стенда: граф, вектор, тест памяти, объекты

## 0. Откуда подшаг
Владелец 2026-09-13, поздний вечер, дословно: «Да, делай вкладки навыков, потом продолжай API , исправить
документацию, которая сейчас обещает лишнее». «Да» — на предложение агента: граф → `use-knowledge-graph`,
вектор → `use-vector-store`, тест памяти → `use-tables` + `use-depth-ladder`, объекты → к `describe-incoming-object`
добавить `use-object-store`. Исход A — те же стенды, что у 194-6.

## 1. Что строится
- `app/[lang]/settings/_lib/stand-skills.ts` — единственный источник «стенд → навыки», по порядку.
- `app/[lang]/settings/_lib/test-tabs.ts`: разделы со строкой вкладок — три стенда хранилищ и `memory-test`;
  у трёх — загрузка · поиск · оценка · навык, у теста памяти — «Тест» · «Навык». 🪦 Закон 194-6 «у графа и
  вектора навыка этой вкладки нет» снимается надгробием со словом владельца.
- `app/[lang]/settings/_components/stand-skills.tsx` — серверный вид: каждый навык свёрнутой карточкой
  `SettingsCard`, текст файла байт в байт; единственный навык раскрыт; нет файла — строка словами с путём.
- `page.tsx`: навыки читаются с диска только при открытой вкладке; тест памяти на «Тест» показывает прежний стенд.
- Словарь en/ru: подпись «Тест», лид страницы навыков, отказ «файла нет» с подставляемым путём.

## 2. Что считается готовым
На каждом из четырёх стендов есть вкладка «Навык», и она показывает ровно те файлы навыков, что лежат в
`.claude/skills/`, — у теста памяти и объектов по два.

## 3. Чем доказывается — названо заранее
- **A (сборка/разметка на сервере):** в собранном чанке страницы есть имена всех шести навыков из
  `stand-skills.ts`; `sha256` шести файлов на сервере = в git (снят до правки: совпадают).
- **B (глаза владельца + негатив):** владелец открывает `?section=graph-test&tab=skill`,
  `vector-test`, `memory-test`, `object-test` и видит тексты; негатив — `?section=memory-test&tab=upload`
  падает на «Тест», а не на пустой экран (проверка `resolveTestTab` прибором или живым адресом).
