# 194-10 — код как объект: загрузка, описание, сохранение, просмотр

## 0. Откуда подшаг
Слово владельца 2026-09-13, дословно: «vedeo , image , pdf, md was tested resoutl greate , but У меня не
получилось загрузить файлы ts,tsx подозреваю что и другие файлы такого типа не поддерживаются?
Разработать процедуру которая позволит в том числе загружать такие файлы генерировать описание генерировать
сама ну в общем все то же самое и просмотрщик кода у нас тоже есть который позволяет просматривать элементы
без необходимости конечно их запускать». Исход A: та же способность стенда объектов.

## 1. Почему код не проходит — по чтению кода (подтверждается прибором)
- `.ts` браузер и Windows отдают как **`video/mp2t`** (MPEG-транспортный поток). В `describe.mjs` расширения
  `.ts` нет ни в одном списке → срабатывает `mime.startsWith("video/")` → род «видео» → ffmpeg не находит
  кадров → `describe-ffmpeg-failed`. Слой данных на `video/*` зовёт `probeDuration`.
- `.tsx` приходит без `mime` → род не определён → `describe-kind-unsupported`.
- Экран считает текстом только `csv|html|json|md|tsv|txt|xml|yaml` → для кода обязательно ручное саммари,
  описание модели отказывает → «Сохранить» заблокирована.

## 2. Что строится
1. **`_tools/code-view/`** — копия инструмента FNS (`tool.json`, `client/code-view.client.tsx`,
   `types/code-view.ts`). Адаптации поимённо: подсветка через `streamdown` вместо `shiki` (пакета на сервере
   памяти нет — та же причина, что в 194-8); список расширений вынесен в `types/code-langs.mjs`, который
   `code-view.ts` переэкспортирует, — чтобы его без сборки читали и `describe.mjs`, и приборы.
2. **Один список кода на продукт:** `describe.mjs` (род `code`, проверка расширения ДО `mime`),
   `objects.ts` (`isTextName` — начало исходника ложится в карточку), экран (саммари для кода необязательно,
   как у текста). Второго списка нет.
3. **Описание кода:** Claude читает файл; `full` — назначение, устройство, экспорт и зависимости, и **исходник
   дословно** в блоке кода, если он короче 12 000 знаков (иначе — структура и ключевые фрагменты с названной
   причиной); саммари — что делает файл, ~50 слов.
4. **Хранение:** для кода в медиатеку уходит `text/plain; charset=utf-8`, а не браузерный `video/mp2t` —
   иначе дверь файла отдаст исходник как видео. Дверь `object-file` для кода отдаёт тот же тип.
5. **Роды строки таблицы:** `text · markdown · html · code · pdf · image · audio · video · document`
   (Markdown и HTML — ответ на «проверь, что … в равной степени»). `CHECK` не меняется `ALTER`-ом: таблица
   пересоздаётся **кодом**. 🛑 Разрушительная операция объявлена заранее; выполняется только при
   **нуле строк**, проверенном в момент выполнения.
6. **Просмотр:** `ObjectPreview` для рода `code` зовёт `CodeView`.

## 3. Что считается готовым
`.ts` и `.tsx` выбираются, описываются, сохраняются и открываются просмотром кода; строка таблицы несёт `code`.

## 4. Чем доказывается — названо заранее
- **A — прибор на сервере:** настоящий `.ts` из репозитория с `mime` `video/mp2t` и `.tsx` без `mime` →
  описание 200, род `code`, исходник дословно в полном описании; сохранение → строка `kind=code`,
  дверь файла `text/plain`, байты совпадают.
- **B, негатив:** настоящий `.mp4` с тем же `video/mp2t`-подобным путём по-прежнему описывается как видео
  (проверка расширения не ломает видео); глаза владельца.

## 5. Цена
Прибор — 2 хода Claude по подписке (файлы `.ts` и `.tsx`), без расшифровки. Подагентов нет.

## 6. Чего не входит
Запуск кода (владелец: «без необходимости конечно их запускать»), текст главной страницы (ждёт его «да»).
