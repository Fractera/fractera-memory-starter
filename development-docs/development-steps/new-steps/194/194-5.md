# 194-5 — результат под формой

## 1. Что строится
После сохранения: сам файл (картинка · плеер · ссылка), полное описание, саммари и таблица из одной
строки со всеми колонками; горизонтальная прокрутка в своём контейнере.

## 2. Что считается готовым
Всё записанное видно на одном экране без перехода.

## 3. Чем доказывается
- **A:** дверь отдаёт строку по id; колонки совпадают с формой 194-1.
- **B:** глаза владельца.
