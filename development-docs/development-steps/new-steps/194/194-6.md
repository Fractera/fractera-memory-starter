# 194-6 — навык и вкладка «Навык»

## 1. Что строится
`.claude/skills/describe-incoming-object/SKILL.md` на английском: что делает агент памяти, когда объект
пришёл из API — описать, сохранить, связать, ответить. Вкладка `skill` только у стенда объектов; текст
читается с диска на каждый запрос.

## 2. Что считается готовым
Текст навыка виден на вкладке и совпадает с файлом.

## 3. Чем доказывается
- **A:** sha256 навыка на сервере = в git.
- **B:** страница вкладки отдаёт первую строку навыка.

## 4. Чего не входит
Подключение навыка к `/v1/remember`.
