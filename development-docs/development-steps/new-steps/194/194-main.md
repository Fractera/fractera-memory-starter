## 3. Решения агента — подтверждены планом

1. **Связи с предыдущими сообщениями и с реестром — тонкими таблицами-указателями, а не массивом в
   строке** (закон службы 3600, шаг 145: список внутри строки не индексируется и врёт при удалении).
2. **Добавленные колонки:** `who` · `source` (стенд · API · Telegram) · `mime` · `size_bytes` · `status`
   (described · saved · failed) · `error` · `described_by` · `describe_ms` · `language` · `full_chars`.
   🔒 **Место и календарь — поправка владельца посреди 194-1, дословно:** «Похоже в таблице мы забыли
   добавить поля связанные с календарем и гео метками». Добавлено до создания таблицы:
   гео `scope_lat` · `scope_lon` · `scope_radius_m` · `scope_place` · `scope_source` (said · exif · device · guess);
   время `scope_at` (когда произошло, ≠ `created_at`) · `event_starts_at` · `event_ends_at` ·
   `event_time_zone` · `event_all_day` · `event_repeats` (RRULE) · `remind_at`. Имена `scope_*` — из договора.
3. **Теги** — колонка JSON без закрытого словаря; модель предлагает 3–7 слов для grep.
4. **Саммари** — в таблицу, в карточку вектора и в граф с якорями из ответа модели; **полное описание** —
   в поле `description` медиатеки рядом с файлом.
5. **Видео:** ffmpeg — дорожка → `whisper-1`; 6 кадров равномерно → Claude; оба текста в одно описание.
   🔒 **Метки времени — решение владельца посреди 194-2, дословно:** «да, добавь метки времени в
   расшифровку». `whisper-1` отдаёт сегменты (`verbose_json`), расшифровка идёт строками
   `[мм:сс–мм:сс]` у аудио и видео; у видео кадры встают между репликами по своей секунде.
   Названы пределы: 25 МБ звука у OpenAI (~50 мин при 64 кбит/с), 20 МБ файла стенда, 6 кадров на любой ролик.
6. **Модель описания:** `claude -p --model opus`, инструмент только `Read`, папка файла через `--add-dir`.
