# 194-8 — просмотр объекта: перенос из медиатеки панели

## 0. Откуда подшаг
Задача владельца посреди шага 2026-09-13: «Посмотри у нас есть вкладка инструменты и там должны
существовать инструменты для просмотра наших объектах аудио видео фото и PDF и HTML… имеет смысл их
разместить в этом же репозитории». Затем, дословно: **«Инструменты тебе не нужно строить их обязательно
нужно скопировать и вставить жёстко перенести и адаптировать»** — это отменяет прежний выбор «строить свои».

**Измерено, где живёт источник:** в `_tools` FNS и живого слота (8 инструментов) просмотрщиков нет.
Настоящий просмотр объектов — **`ai-workspace/bridges/app/app/[lang]/media/_components/preview-popup.client.tsx`**
(медиатека панели, 153 строки): картинка, видео, PDF, Markdown (отрисованным), HTML (страница в песочнице ⇄ код).

## 1. Что строится
`_tools/object-view/client/object-preview.client.tsx` — **копия** `PreviewPopup` + `tool.json` по стандарту
3000. Переносится дословно: определение рода по `mime_type`/`extension`, чтение Markdown `fetch`-ем,
переключатель «код ⇄ страница» у Markdown и HTML, `iframe` для PDF, `sandbox="allow-scripts"` без
`allow-same-origin` у HTML (с его комментарием о паре флагов), подвал «род · расширение · размер».

**Адаптации — поимённо, каждая с причиной:**
1. **Markdown и код рисует `streamdown`**, а не `react-markdown` и `shiki`: на сервере памяти этих пакетов
   нет (измерено), `streamdown 2.6.0` стоит и уже используется. Новый пакет ради одного экрана не заводится.
2. **Аудио добавлено** (`<audio controls>`): у источника его нет, а память принимает голосовые.
3. **Встраивается в блок, а не всплывает поверх экрана:** владелец просил объект внутри того же интерфейса.
   Кнопки «код ⇄ страница», «открыть» остаются; «закрыть» — у всплывающего режима.
4. **Адрес файла — дверь `object-file`**, подписи — из словаря памяти (слова панели перенесены дословно).
5. **Тип входа** — своя копия нужных полей `MediaItem`; данные приходят строкой медиатеки из `messageView`.

## 2. Что считается готовым
Блок «Что легло в память» показывает объект этим инструментом; своя вёрстка превью из 194-5 удалена.

## 3. Чем доказывается
- **A:** дверь `object-file` отдаёт PDF (`application/pdf`), Markdown и HTML с их типами; в сборке есть
  вход инструмента и `sandbox="allow-scripts"`.
- **B, негатив:** HTML-объект открывается без `allow-same-origin` (по разметке сборки); глаза владельца.

## 4. Чего не входит
Редакторы (`image-crop`, `video-trim`), порождённая карта `TOOLS.json`.
