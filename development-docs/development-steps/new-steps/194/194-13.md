# 194-13 — граф получает полное описание с происхождением; связь четырёх хранилищ проверена насквозь

## 0. Откуда подшаг
Слово владельца 2026-09-13, дословно: «ты забыл, что нужно полное описание отправлять в граф одновременно
при этом усилия его дополнительной информации о том откуда поступило это объект в данном случае из тестового
стенда в реальном же случае там должен быть написан реальный источник например Telegram от Рома Амстер, должна
быть написано дата. Логичным образом должна быть создана запись в векторном хранилище, и разумеется созданной
связи между всеми четырьмя базами что должна отображаться в таблице. Замечательным образом проверь эту часть
работы архитектуры именно для этого мы создавали… Это критически важно обеспечить пожалуй самый сложную часть
работы архитектуры с объектами.»

**Что было до подшага (измерено чтением `keep()`):** в граф уходили только название, саммари и теги, и только
когда модель дала якоря; происхождения не было; прибор 194-4 проверял «документ принят», а не «разобран и
находится».

## 1. Что строится
- `keep()`: документ графа пишется **всегда**. Текст — название, **полное описание** (нет его — саммари), теги,
  id объекта и имя файла. Шапка «Откуда это известно» — **источник** (тестовый стенд · API · Telegram) ·
  **кто прислал** · **дата и время UTC**. Якоря — от модели; нет их — название объекта. Якоря переданы, но все
  пустые — это ошибка присланного: граф отказывает, откат, строка `failed` (прежний негатив сохранён).
- `messages_that_came_into_memory`: поздняя колонка **`author`** (лестница `LATE_COLUMNS`).
- Дверь сохранения: `author` — email архитектора из сессии замка (у прибора — «прибор, секрет машины»);
  `source` — `stand`, если не передан иной.

## 2. Что считается готовым
Из одной строки таблицы доходят до всех четырёх: файл в медиатеке · карточка в векторах · документ графа
разобран (`processed`) и содержит полное описание и происхождение · граф отвечает на вопрос об объекте.

## 3. Чем доказывается — названо заранее
- **A — прибор `scripts/probe/object-four-stores.mjs`** через публичный адрес, без модели описания: сохранить с
  уникальным словом в полном описании → по ссылкам строки: медиа есть, вектор есть, документ графа по `rag_source`
  дошёл до `processed` → вопрос графу с уникальным словом возвращает контекст с этим словом и происхождением.
- **B, негатив:** якоря из пробелов → откат и строка `failed`; вопрос графу с заведомо отсутствующим словом не
  возвращает уникального слова объекта.

## 4. Цена
Разбор документа графом (OpenAI, модель графа) и одно встраивание; хода Claude нет.
