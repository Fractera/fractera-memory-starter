# 194-2 — дверь «описать объект»

## 1. Что строится
`lib/describe.mjs` + `POST /api/fractera/object-test/describe` (multipart). Файл → временная папка → по
роду: аудио — `whisper-1`, затем текст расшифровки описывает Claude; видео — ffmpeg дорожка + 6 кадров;
картинка / PDF / текст — `claude -p --model opus` с инструментом `Read`. Ответ
`{ title, full, summary, tags, anchors, kind, described_by, ms }`. Отказы словами: нет ключа, нет денег,
лимит подписки, род не описывается, файл слишком большой. Временная папка стирается в любом исходе.

## 2. Что считается готовым
На картинке, PDF и аудио приходит JSON по форме; саммари 35–70 слов.

## 3. Чем доказывается
- **A:** ответ двери на трёх файлах дословно.
- **B, негатив:** файл `.exe` → отказ «род не описывается», модель не зовётся (время меньше секунды).
