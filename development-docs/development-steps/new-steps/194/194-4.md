# 194-4 — сохранение объекта целиком

## 1. Что строится
`keep()` принимает `full`, `summary`, `title`, `tags`, `anchors`: файл + полное описание → медиатека;
карточка вектора из саммари; граф `learn` с якорями; строка `messages_that_came_into_memory` со ссылками
на все три. Любой сбой → откат уже положенного и строка со `status = failed` и `error`.

## 2. Что считается готовым
Одно нажатие «Сохранить объект» даёт файл, карточку, документ графа и строку, связанные между собой.

## 3. Чем доказывается
- **A:** строка таблицы и три ссылки существуют — запрос мимо кода памяти.
- **B, негатив:** граф недоступен → медиа и вектор откатились, строка `failed`.
