# 206-5 — Кейсы стенда переезжают из таблицы в файл

## Откуда
Ответ владельца на форму 2026-09-15, дословно: **«Убрать тоже»** — про `memory_bench_cases`.

## Что строится
- Кейсы переезжают из таблицы в файл репозитория (рядом со стендом), правка — обычным коммитом.
- `lib/cases.mjs` и его дверь снимаются; потребители — `app/api/fractera/bench-cases`,
  `graph-search`, `link-search`, `object-search`, `vector-search` — читают файл.
- Приборы `scripts/probe/bench-cases.mjs` и `bench-cases-sort-delete.mjs` перенацеливаются на файл
  либо снимаются вместе с предметом.

## Что считается готовым
Стенд показывает те же кейсы, а в слое данных таблицы кейсов нет.

## Чем доказывается
1. **Счёт:** имя таблицы кейсов в коде 0, файл кейсов читается; негатив — пустой файл даёт пустой стенд.
2. **Живая страница стенда** показывает кейсы после удаления таблицы.
