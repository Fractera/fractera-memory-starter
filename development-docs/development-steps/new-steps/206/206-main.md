# Шаг памяти 206 — «Память живёт одной таблицей»

## 1. Откуда шаг

Решение владельца 2026-09-15, дословно:

> «Восемь весь день работаем над памятью, разом переписываю инструкции , мы зашли в тупик потому что я
> решил твою работу с реестром признаков. Более того я хочу чтобы наша память вообще прекратила работать
> с какими-либо специализированными таблицами кроме одной-единственной который фиксирует все входящие
> сообщения и записи от базы данных. Мы её уже сделали. Таким образом что бы не говорили другие
> пользователи памятник не создают свои таблицы и не читают другие кроме одной единственной таблицы
> сообщений. Почему это будет сделано? Потому что будут другие приложения которые будут заниматься
> этими задачами а память это события вокруг базе для обычной таблицы которые можно создаем для граф
> для вектора и для въездного хранилища то есть всё делаем проще понятнее быстрее с фокусом на
> интеллект агенты которые этим занимаются».

Предыдущее решение того же дня — реестр признаков удалён целиком (`27a9bf7`, договор 3.0.0).
