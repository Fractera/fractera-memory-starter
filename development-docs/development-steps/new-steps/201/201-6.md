# 201-6 — чтение: таблица или граф одиночным решением, указатель → строка, честное «не знаю»

## 1. Что строится
- `recall`: одиночный вызов без нити (201-4) решает по вопросу — **точное/счётное/текущее** (признак найден) → таблица: код собирает запрос по
  выбранным ключам (последнее значение, список, сумма за период); **остальное** → граф с ключевыми словами от памяти; найденные в графе указатели
  разворачиваются кодом в строки таблиц и объекты.
- Объекты: фильтр по `who` и по роду намерения вопроса (ТЗ `200-9` влито сюда); у каждого значения и объекта — `found_by` (table · graph · object).
- Ничего не нашлось — честное «не знаю»; «всё известное» — только без вопроса или по явной просьбе.
- `BUILT_LEVELS` и `depth_used` — правда о том, какие ступени построены и пройдены.

## 2. Что считается готовым
Вопрос человека на любом языке получает ровно нужное — из таблицы, если это точное, или из графа, — либо честное «не знаю».

## 3. Чем доказывается
- **A:** матрица 200-7 со строгим судьёй (ровно нужный факт), по-русски и по-английски: «сколько я потратил сегодня?» → 900; «где я живу?» →
  Севилья; «что было с Денисом?» → история из графа с якорем; оценки «правильно» не ниже названного до прогона числа.
- **B (негатив):** «какая порода у моей собаки?» → «не знаю» без фактов; «скан паспорта» от `probe` → объект чужого `who` не приходит; вопрос о языке
  не отдаёт встречу (ложное совпадение E8 исчезло).

## 4. На что опирается
201-3, 201-4, 201-5.

## 5. Чего не входит
Паритет потребителей как отдельный замер (201-7).
