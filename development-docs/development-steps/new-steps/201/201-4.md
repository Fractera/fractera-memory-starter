# 201-4 — подбор схемы: индекс реестра по смыслу и одиночный вызов без истории

## 1. Что строится
- `lib/features/index.mjs` — встраивания записей реестра (`title` + `triggers` + `answers`), перестраиваются при правке реестра; поиск K ближайших
  (K и порог — из 201-2).
- `lib/features/discover.mjs` — одиночный вызов модели **без нити**: вход — фраза человека (любой язык) и K кандидатов с их смыслом; выход —
  выбранные ключи, извлечённые значения, глубина (§3п), решение «таблица/граф» по типу и накоплению, либо «ни одного». Результат не сохраняется
  в нити и не попадает в кэш разбора.
- Присланные зовущим признаки (ключи) пропускают подбор, но значения проверяются по типу.

## 2. Что считается готовым
По любой фразе память за один одиночный вызов получает признаки из небольшого числа кандидатов, не видя всю схему.

## 3. Чем доказывается
- **A:** прибор на фразах владельца (расходы, Денис, город, язык) по-русски и по-английски — нужный ключ среди кандидатов и выбран; на 1000
  синтетических записей время подбора в пределах замера 201-2; в подсказке модели не больше K записей (счёт по журналу вызова).
- **B (негатив):** несвязанная фраза («почему корабли не тонут») → «ни одного»; ответ вызова без имени нити; признак неверного типа от зовущего
  отвергнут с причиной.
