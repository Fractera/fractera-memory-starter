## Что делали и как
- Владелец спросил, почему при первом разговоре о ссылках я не предложил гарантированный путь к данным ролика. Поиск по истории нашёл его
  прошлый случай: пост про Илона Маска, ролик `BYXbuik3dgA`, метка 4119 с. **Способ восстановлен измерением: секунда взята из ГЛАВ, которые
  автор пишет в описании, а описание официальный API отдаёт по ключу.**
- `lib/youtube-chapters.mjs` — разбор глав, узнавание адреса ролика, секунда из адреса. **На JS, чтобы прибор проверял тот же код, а не копию.**
- `lib/fractera/youtube.ts` — `videos.list`, снимок-Markdown, канонический адрес, обложка.
- Карточка «Ключ YouTube Data API» в «Настройках» с шагами получения (слово владельца), дверь `youtube-key` под ролью `architect`, ключ в
  складе секретов машины построчно; наружу — «задан» и четыре знака.
- Отказы стандартизированы **по документации Google** (слово владельца): `not-youtube` · `youtube-key-missing` · `youtube-key-rejected` ·
  `youtube-quota` · `video-not-found` (удалён, приватный или опечатка — API не различает, так и сказано) · `youtube-refused` · `youtube-unreachable`.
- Обложка ложится отдельным объектом `kind=image` и связывается с записью ролика. **Для этого заведён писатель `linkMessages`: таблица связей
  жила с 194-1 без единого писателя** — способность, написанная и не подключённая (закон 143).

## Ошибки
- ✗ **API называет размер обложки, которого на складе нет.** `fhd` 1920×1080 назван, а `fhddefault.jpg` отдал **`404` телом в 1097 байт с типом
  `image/jpeg`** — по содержимому картинка, и только код ответа говорит правду. Первый прогон с ключом дал 2 ✗ и нашёл это.
  🔒 **Закон: адрес, названный чужим API, проверяется фактом** — тот же класс, что «адрес ресурса берётся из страницы, а не собирается по
  шаблону». Лечение `6bcf590`: обложка выбирается сверху вниз по коду ответа, в снимке назван размер и что он проверен.
- ✗ Ошибка постановки, признанная агентом: факт «ключ полезен для `videos.list`, не для субтитров» был записан в плане федерального 198, но
  данные ролика не были предложены владельцу отдельным гарантированным потоком — всё сводилось к трудной расшифровке.
