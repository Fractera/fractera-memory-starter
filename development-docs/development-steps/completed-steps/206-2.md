# 206-2 — Порог 2000 слов и вектор у сказанного. Итог

**Коммит:** `4737cc9` (вместе с 206-9), доставлен, `BUILD_RC=0`, порт за 7 с, договор живьём **4.0.0**.

## Что сделали

- `lib/said-vector.mjs` — один хозяин порога: `MAX_WORDS_FOR_MEANING = 2000`, счёт слов, вердикт
  СЛОВАМИ (причина едет в ответ и в журнал) и запись куска смысла в коллекцию `memory-said`.
- Решение «куда ложится сказанное» собрано в ОДНОМ месте (`toGraph` в `lib/verbs.mjs`): сказанное
  сохраняется из трёх точек глагола, и порог, написанный в одной, молча не сработал бы в двух других.
- Короче порога: связи **и вектор**, под одним именем документа.
- Длиннее: целиком в объектное хранилище тем же путём, что присланный файл (`keepLongText` →
  дверь `object-ingest` через новый `doorForm` петли), **и без вызова модели** — разбирать то, чему
  некуда лечь, значит тратить ход подписки зря.

🔎 **Дорогой факт, ради которого шаг и был нужен:** векторное хранилище звали ТОЛЬКО стенды
(`app/api/fractera/vector-{search,test}`). Путь записи не клал в него ни одной фразы человека — то
есть «память ищет по смыслу» было правдой про объекты и неправдой про слова.

## Доказательства

**Плоскость 1 — граница числом** (прибор `scripts/probe/meaning-threshold-206-2.mjs`, локальные
чистые функции): `2000 слов — ещё короткое`, `2001 — уже длинное`, счёт слов точен. Негатив в самой
паре: проверка «примерно длинным» текстом прошла бы при любом пороге.

**Плоскость 2 — живая служба на сервере:**

```
✓ короткая фраза легла в связи и в вектор: graph+vector — {"id":"memory/probe-206-2/2026-09-15T22-11-52-124Z","ok":true}
✓ короткая фраза разобрана моделью — так и задумано
✓ длинный текст ушёл в объекты: objects
✓ у объекта есть идентификатор: 50341aa4-a42f-475b-9aec-f5286aacc1d9
✓ модель на длинном тексте не звалась — ход сэкономлен
```

Что доказывает: два одинаковых по смыслу текста уезжают разными путями, и путь назван в ответе.
Без правки оба пошли бы в связи, вектор не получил бы ничего, а длинный текст стоил бы вызова модели.

## Ошибки

Ошибок подшага нет — строка написана намеренно, а не опущена.

## Эволюция навыков

`use-vector-store` описывает поиск по смыслу так, будто склад полон; до этого подшага туда попадали
только карточки объектов. Навык правится в 206-7 вместе с остальным корпусом.
