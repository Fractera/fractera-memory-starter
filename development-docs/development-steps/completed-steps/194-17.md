## Что делали и как
- `lib/loopback.mjs` — один мост модулей `server.mjs` в двери памяти по петле с секретом машины; `media-ingest.mjs`
  переписан на него.
- `lib/object-verbs.mjs`: `find_objects` зовёт дверь `object-search` с признаком `probe` (поиск чужой программы не
  пишет случаи стенда) и дополняет каждую находку строкой таблицы — `messageId`, `kind`, `title`, `summary`;
  `open_object` зовёт `object-open` и называет адрес файла.
- `server.mjs`: оба метода в `RUN` — общая ветка проверяет обязательные параметры по договору; `GET /v1/objects/{id}/file`
  течёт потоком из `object-file` с её типом, именем и длиной.
- `contract.mjs` 2.5.0: методы `find_objects`, `open_object`, адрес файла в каталоге.

## Доказательства
**A — сеть снаружи, положительный путь** (`node scripts/probe/v1-objects.mjs`, публичный адрес, ключ памяти):
```
✓ договор называет find_objects, open_object и адрес файла
✓ find_objects: найдено 5, README на месте, messageId 33, kind markdown, score 0.46522185009972167
✓ open_object: текст 12000 из 26931, file /v1/objects/7e287f3d-…/file
✓ файл объекта: 200, 286835 байт, тип image/jpeg, sha256 совпадает: true
```
Доказывает: объект, положенный через договор, находится вопросом другими словами вместе со своей строкой таблицы,
открывается текстом частями, а файл возвращается байт в байт. Без правки: `POST /v1/find_objects` получал отказ
«не построено», адреса файла не существовало.

**B — негатив, тот же прибор:**
```
✓ файл без ключа → 401
✓ негатив поиска: found false, результатов 0, объектов прибора среди них нет
✓ open_object чужого id → not-found
✓ файл чужого id → 404
✓ уборка: строк убрано 3, документов графа было 3, осталось 0 · ✓ OK · PROBE_RC=0
```
Прибор 194-15 и 194-16 при этом остался зелёным целиком.

## Ошибки
- План называл отказ чужого id у `open_object` кодом `404`; общая ветка договора отвечает `200` с `ok:false` и
  `error: not-found` — так же, как остальные методы. Код `404` остался у адреса файла, где тело — байты, а не JSON.
- В журнале памяти осталась ещё одна запись прибора от `remember` (см. 194-16).
