## Ошибки

- Первые тексты (`54576e2`) писали «8 кандидатов» и для записи — верно только для чтения; найдено сверкой с `verbs.mjs`.
- Поиск читателей `ladder` смотрел только в `app/` — `lib/llms.ts` и `lib/markdown-mirror.ts` нашла проверка типов.
- `llms.txt` нёс вписанный руками заголовок «Cost ladder» над новой схемой — вторая доставка.
- Скрипт замены словаря не нашёл блоков: файл с `\r\n`; образец блока совпадал и с описанием типа — узнаётся по первой строке.
- Образец проверки «2.2.1» искал 3 пробела вместо 6 — ошибка образца, не страницы.
- Главный урок шага: сценарий записи был написан по памяти агента, а не по паспорту, — владелец: «У меня такое ощущение что ты вообще не
  понимаешь что мы делаем?». Описание замысла пишется **после чтения паспорта и навыков**, не до.
