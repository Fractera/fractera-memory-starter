## Что память умеет сегодня и чем доказано

- **Положить вещь целиком** (стенд — файлом, агент — своим Markdown) и получить вечный id.
- **Найти вещь по смыслу** другими словами и на другом языке: 15 из 15 нужных в пятёрке и выше
  порога, 5 из 5 посторонних отсечены; медиана поиска ~225 мс, ходов модели ноль.
- **Открыть:** текстовый объект — кусками по 12 000 знаков с названным пределом; двоичный — только
  карточкой, с прямым «содержимое этого рода не читается».
- **Отказы различаются:** путь сломан · вещи нет (с ближайшим числом) · id чужой · файл пропал.

## Чего не умеет — долг, названный вслух

- **Не смотрит внутрь изображений, PDF, звука, видео** — находит их только по описанию. Это
  мультимодальный конвейер, отдельная работа.
- **Абзац из глубины длинного документа поиск объектов не видит** — карточка несёт первые 1500
  знаков. Правило в навыке учит обходить это за один лишний поиск, но сама граница остаётся.
- **Изоляция корпусов** стенда и агента — одна коллекция `memory-objects` (долг, унаследованный от 189).
- **Удалять и менять объекты агент не может**, только класть.
- **Оптимизация описания навыка на срабатывание не запускалась** — общая квота; причины в отчёте 192-5.
- **Экран стенда глазами не видел никто** — страница под ролью `architect`, недостижима прибором.

## Решения агента по переданному полномочию

1. Объекты живут в медиатеке слоя данных (развилка §16.8 паспорта) — дорога графа и вектора; цена —
   объекты памяти видны в общем списке медиатеки; обратимо правкой одного файла.
2. Поиск — по карточке в векторном складе со ссылкой `ref_table=media`.
3. Рук три, включая запись: объект-ответ сочиняет агент (§14.2).
4. Порог 0.30 — середина измеренного зазора.
5. **Демонстрационный корпус (32 файла FES) оставлен в складе**, чтобы стенд и агент было на чём
   проверить. Убрать — кнопка «Забыть все объекты памяти» на вкладке «Загрузка» или
   `DELETE /api/fractera/object-test` секретом машины.

## Ошибки шага

- heredoc с обратными кавычками разорвал оболочку — ТЗ переписаны редактором (закон проекта сработал
  так, как записан: знание его не исполнило).
- `base64 -d` без перевода строки — MCP-сервер не видел запрос.
- Заголовки Markdown в журнале вызовов принимались за вызовы — узнаются по метке времени.
- Агрегатор skill-creator ждёт `eval-N/<конфигурация>/run-1/` — итерация 1 переложена.
- Признак 4.4 («ответ короче 1500») несовместим с обязательными полями ответа по инструкции агента —
  назван, не подогнан.
- `192-5-corpus-ids.txt` снят с корпуса, загруженного для прогона навыка; после финальной перезагрузки
  корпуса id объектов другие — файл остаётся свидетельством прогона, а не картой склада.
