## Что делали и как

Прибор `development-docs/instruments/201-2-costs.mjs` прогнан на сервере из `/opt/fractera/memory`; числа и выводы —
`development-docs/instruments/201-2-costs.md`. Три замера: **V** — индекс 1000 записей реестра по смыслу (12 настоящих + 988 близких
соседей) и 9 вопросов; **M** — один вызов `claude -p` на подбор признаков по 8 кандидатам, Opus и Sonnet, с сохранением разговора и без;
**G** — запись в граф и чтение с нашими словами, затем второй проход `graph2` по месту сущности. Прибор не зовёт `think()`, потому что тот пишет
в живой журнал памяти; аргументы CLI повторены поимённо.

**Главные числа.** Подбор схемы: поиск кандидатов ~200–280 мс (почти всё — встраивание вопроса), нужный признак в первых двух 8 из 8, порога
близости нет (верный 0,249 против постороннего 0,241) → кандидаты числом. Один вызов Opus без сохранения: 3,9–4,2 с модели, 6–7,2 с стены,
верен 4 из 4; Sonnet 1 из 2 и не быстрее. `--no-session-persistence` не оставляет разговора и не даёт его продолжить. Граф: запись принята
за 21 мс, готова через 2,3–6,2 с, модель графа на записи зовётся всегда; чтение с нашими словами 0 ходов модели, 231–2998 мс; «не знаю» граф
сказать не умеет — это делает поиск метки.
