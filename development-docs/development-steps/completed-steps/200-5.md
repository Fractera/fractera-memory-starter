## Что делали
**API (договор 2.6.0, MINOR — прежние вызовы не изменились):**
- `remember` — `body: json | multipart`; новые параметры `files` (части формы), `links` (страницы), `youtube` (ролики); форма — часть `payload` с тем же JSON и части `files`.
- `server.mjs` — форма `POST /v1/remember` уходит потоком (`passToDoor`) в новую дверь `app/api/fractera/remember-ingest/route.ts`: обязательное проверяется
  до файлов тем же `missing-params`, файлы — `ingest()` (путь `keep_object`), затем `remember()`; судьбы — в `objects`.
- `lib/link-ingest.mjs` — `ingestLinks()`: род по `youtubeId()` (`link-is-youtube` / `youtube-not-youtube`, без записи), иначе двери стенда ссылок по петле —
  `link-test/describe` (ролик — официальный API, страница — ИИ-браузер) → `link-ingest` той же формой, что шлёт стенд; обложка и сниппет не кладутся.
- `lib/params.mjs` — SPEC `links`, `youtube`; `lib/verbs.mjs` — вызов рядом с `media`; `proxy.ts` — имя двери; `next.config.ts` — `proxyClientMaxBodySize: "200mb"`.
- Вкладка API: переводы `files` / `links` / `youtube`, исправлен перевод `media` (обещал «метода для ссылок нет»).

**Стенд:**
- `lib/kinds.mjs` — роды файлов вынесены из `describe.mjs` (тот тянет `child_process`), `UPLOAD_KINDS`, `acceptOf()`; `code-langs.mjs` — `codeExtensions()`.
- `lib/bench-call.mjs` — `files` едут частями формы только туда, где договор их объявляет; `links`/`youtube`; `invalid` — ссылки не своего рода.
- Органы — девятый ряд «Вложения»: шесть кнопок загрузки, порождённых из родов памяти, список выбранных файлов, поля «Обычная ссылка» и «Ссылка YouTube»
  с проверкой рода на экране.
- Стенд — при файлах форма в дверь стенда `?method=remember` (поток `duplex: half` в `/v1/remember`), кнопка заперта при `invalid`, под ответом судьба каждого вложения.
