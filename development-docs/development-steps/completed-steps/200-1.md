# 200-1 — дверь стенда ходит только в публичный `/v1/*` — ЗАКРЫТ 2026-09-14

**Код:** `fractera-memory-starter`, ветка `new-step-200`, коммит `84aa4a3`. Доставлен `deliver-memory.sh 48b775e`: `BUILD_RC=0`, порт через 4 с.

## Что делали
`app/api/fractera/memory-test/route.ts` переписан из вызова исполнителей ядра в проводник публичного API:
- `POST { method, body }` → `POST https://<хост запроса>/v1/<метод>` с `x-memory-key`; тело уезжает как набрано, имя метода со списком не
  сверяется — отказ `not-built` отдаёт сама память;
- `POST { get }` → каталог: `tables` · `tables/<имя>` · `health` · `contract` · `objects/<id>/file` (у файла — тип, имя и число байт, тело не собирается);
- `GET ?what=tables | ?what=table&name=` — для раздела «Что память построила»;
- ответ экрану: `request { method, url, headers (ключ маской), body }`, `status` (код `/v1`), `ms`, `body` (сырой ответ), `trouble`, и прежний `sent`
  для совместимости клиента до 200-2.

## Решения, принятые по ходу
- 🛑 **Ключ уходит только адресу этой машины.** Адрес выводится из `Host`, который пишет клиент; подделанный `Host` увёл бы ключ. Домен разрешается и
  сверяется с адресами интерфейсов, перенаправления не выполняются. Измерено до кода: `213.199.61.7` стоит на `eth0`, домен разрешается в него.
- Нет файла ключа — вызов идёт без ключа: отказ `no-access` есть ответ договора, стенд его показывает.
- Предел ожидания 600 с: у nginx `proxy_read_timeout 86400`, ход модели на глубине идёт минутами.

**Без правки было бы:** в журнале ни одной строки `/v1/*` от `213.199.61.7`, а `?what=tables` → `405` (до правки — 14 таких строк).

полный ключ (`fmk_` + 8 и больше знаков) в шести ответах — 0. **Без правки было бы:** отказ исполнителя без `missing`, и `not-built`, сочинённый дверью.

## Попутная находка
Раздел таблиц стенда был мёртв с 178-1: клиент звал `GET`, дверь его не держала — журнал nginx, 14 × `405`. Исправлено этим подшагом.
В ответе `/v1/tables` поле называется `records`, а клиент таблиц читает `rows` — число строк у имени не показывается; идёт в 200-2.

## Эволюция навыков
`use-testing`: пара «вызов из вкладки владельца → строка `/v1` с адреса сервера в журнале nginx в ту же секунду» — дешёвое доказательство пути для
любой двери-проводника; при чтении журнала nginx сверять часовой пояс сервера. Правка навыка — при закрытии шага, записано здесь, чтобы не потерять.
