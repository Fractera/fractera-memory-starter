# 195-5 — навык `use-links`: чем агент располагает, когда речь о ссылке

**Коммит:** `5013f6a` (ветка `new-step-195`). **Дата:** 2026-09-14. **Решение владельца:** «195-13 и навык, потом закрыть» — из прежнего
состава 195-5 построен только навык; главная и страница API сделаны в 195-13.

## Что делали и как
- `.claude/skills/use-links/SKILL.md` — по-английски (машинный слой памяти одноязычен), у стенда ссылок вкладка «Навык» его показывает: имя в
  `stand-skills.ts`, файл читается с диска на каждый запрос, второй копии текста нет.
- Внутри: **сохранённая ссылка есть объект, у которого источник — адрес**; таблица «что в снимке есть и чего в нём нет»; главы как ответ на «на
  какой минуте»; **измеренная невозможность расшифровки** (`captions.download` → `401`); какие руки у агента есть и **что руки для ссылок у него
  нет вовсе** — ссылку кладёт человек на стенде, и договор 2.5.1 это говорит; как читать сохранённую ссылку (`find_objects` → `open_object` →
  главы внутри снимка, `ask_graph` по происхождению); **почему имя с ошибкой не находится** — таблица чисел из замера; восемь отказов с тем, что
  делать по каждому; канонический адрес ролика и сниппет как связанный объект.
- ✗ Найдено до прогона чтением `page.tsx`: общая ветка стенда ссылок перехватывала и вкладку «Навык» — навык не показался бы. Порядок ветвей
  исправлен, лишняя заглушка удалена.
