# 201-6 — чтение: таблица или граф одним решением, честное «не знаю»

**Коммиты:** `fractera-memory-starter`, ветка `new-step-201` — `456b81d` (чтение целиком), `155b22a` (роды реестра в подсказке записи,
основы имени при поиске меток), `f204a8c` (реестровые роды первыми). **Доставлено:** `DELIVERED_COMMIT=f204a8c`.
**Дата:** 2026-09-15 (00:18 UTC).

## Что делали и как

| Что | Где |
|---|---|
| решение «таблица или граф», сумма кодом, имена для графа, фильтр объектов | `lib/read.mjs` |
| чтение по признакам, честное «не знаю», уровни глубины | `lib/verbs.mjs` → `recall` |
| правда о построенных ступенях: **три**, а не две | `lib/params.mjs` → `BUILT_LEVELS` |
| «этого я не знаю» словами на двух языках | `lib/words.mjs` |
| «о ком» у найденного объекта | `lib/object-verbs.mjs` |
| прибор | `scripts/probe/read-201-6.mjs` |

**Порядок чтения теперь такой.** Вопрос → один вызов модели по кандидатам реестра (201-4) называет признак → отвечает **код** из таблицы,
и `sum-able` он **складывает сам** → признака нет или значений под него нет → имена из вопроса проверяются по меткам графа → и только если
имя графу известно, задаётся вопрос о связях → иначе **честное «не знаю»**.

🪦 **МЕХАНИЧЕСКИЙ ПОИСК СЛОВ ВОПРОСА ПРОТИВ ЧАСТЕЙ ИМЕНИ РОДА УДАЛЁН** (решение владельца 2026-09-14 об аннулировании обещания «без ИИ»).
По-русски он промахивался всегда, по-английски давал уверенные ложные совпадения по служебным словам.
🔒 **«ВОТ ВСЁ, ЧТО ИЗВЕСТНО» БОЛЬШЕ НЕ ОТВЕТ НА ВОПРОС** — только на его отсутствие. На конкретный вопрос это перекладывание работы на
спросившего и повод принять чужой факт за свой.
🛑 **ГРАФ СПРАШИВАЕТСЯ ТОЛЬКО ПО ИЗВЕСТНОМУ ИМЕНИ:** он не умеет отвечать «не знаю» (измерено 201-2), поэтому существование имени
проверяется поиском по меткам — без хода модели.

## Доказательства

**A — пять вопросов со строгим судьёй (ровно нужный факт, а не его присутствие):**
```
✓ «сколько я потратил сегодня?» → верно · глубина 2 · чем достали: table+sum,table · 8023 мс
      ответ: spent on a purchase: всего 900 (сложено из 3); …
✓ «где я живу?» → верно · table · 5330 мс          ✓ «where do I live?» → верно · table · 5071 мс
✓ «как меня зовут?» → верно · table · 8771 мс
✓ «что было с Денисом?» → верно · глубина 3 · чем достали: graph · 7392 мс
```
Доказывает: кейс владельца («сколько потратил» → 900) исполняется кодом, а не пересказом; вопрос по-английски работает так же, как по-русски;
история Дениса приходит из графа по якорю, а не из таблицы. Без правки те же вопросы отвечали «вот всё, что известно» либо промахивались
(матрица 200-7: 19 правильных, 9 неправильных).

**B — четыре негатива разной природы:**
1. «какая порода у моей собаки?» → `known` пуст, ответ «этого я не знаю», и **названо, чего не хватает** (`not_yet_known`).
2. Вопрос о языке отдаёт только язык — встречи и прочего в ответе нет (ложное совпадение матрицы исчезло).
3. Объекты чужого человека не приходят: фильтр по «о ком» и по роду вопроса.
4. Без вопроса всё известное отдаётся как прежде: 8 значений, модель не звалась, глубина 1.

## Ошибки

- ✗ **Разрыв между записью и чтением: они звали одно и то же разными именами.** Модель при записи придумывала род
  (`money_he_spent_on_purchases_by_item`), а чтение искало реестровый (`spent_on_a_purchase`) — «сколько я потратил сегодня?» отвечало «не знаю»
  при трёх записанных тратах. Лечение: роды реестра встали в подсказку записи рядом с заведёнными.
- ✗ **Осадок прежних прогонов перетягивал запись на старое имя.** Пустая таблица, оставшаяся от предыдущего опыта, стояла в подсказке наравне
  с реестровым родом — и модель, которой велено «бери имя буква в букву», честно брала её. Лечение: реестровые роды идут первыми, прочие
  помечены «вне реестра». 🔒 **Урок шире случая: в подсказке модели порядок и пометка — это не оформление, а правило выбора.**
- ✗ **«Что было с Денисом?» отвечало «не знаю» при живой метке «Денис»:** поиск меток подстрочный и падежей не знает, а человек спрашивает
  падежами. Лечение — основы имени (усечение до трёх букв, основа не короче четырёх), нестрогость наша, а не движка.
- Все три найдены **прогоном на сервере**, а не чтением кода: ни типы, ни сборка, ни греп их не видели.
