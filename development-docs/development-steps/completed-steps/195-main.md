## Ошибки шага, стоящие памяти
1. **Что положено в снимок, то и станет описанием.** Весь текст в снимке → описание ролика стало пересказом спонсоров.
2. **Отметка оставляет способность живой; «убрать» значит убрать.** HTML был спрятан за флаг вместо удаления, указание пришлось повторить.
3. **Адрес, названный чужим API, проверяется фактом.** Обложка `fhd` — `404` с телом-картинкой.
4. **Таблица связей жила с 194-1 без писателя.** Найдено вопросом «кто её зовёт», а не грепом по имени.
5. **Опора правки, тронутая раньше в той же сессии, устаревает молча.** Скрипты слов дважды давали 0 совпадений.
6. **Эталон негатива сам проверяется до прогона:** у «страницы с кодом 403» может не быть страницы (httpbin отдал пустое тело).
