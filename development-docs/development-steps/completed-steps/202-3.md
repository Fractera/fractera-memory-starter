# 202-3 — «Добавить задание»: туду-список заявок в `pre-steps/`

**Коммиты:** `fractera-memory-starter`, `new-step-202` — `2c63a51` (писатель, дверь, островок), `824a9cd` (прибор). **Дата:** 2026-09-15.

## Что делали и как
`lib/build-tasks.mjs` пишет заявку по формату `pre-steps/README.md` (имя `dd-mm-yyyy_hh-mm-ss.md`, поля `источник · когда · где · что просят ·
чем вызвано`) с защитой текста конструкцией писателя (закон федерального шага 61): внутри «…», переводы строк → « · », закрывающая кавычка
удваивается. Отзыв не удаляет — переносит в `handled/` со строкой «во что превратилась: отозвана человеком со страницы». Время — UTC, названо в
поле. Дверь `build-tasks` (`GET` · `POST` · `DELETE`, `benchGuard`), островок — поле, список «Ждут планирования», «Отозвать». Раздел объясняет
роль заявки и подсказывает фразу для терминала: «запланируй новый шаг разработки по моим заданиям».

## Доказательства
- **A** (`scripts/probe/build-tasks-202-3.mjs`): `добавлено: 200` · файл в приёмной · все пять полей на месте · `список показывает заявку` ·
  `отозвано: 200, в приёмной файла больше нет` · `след в handled/ с пометкой` · `из списка исчезла`. Без правки заданий на странице не было.
- **B**: `без входа и без секрета дверь отвечает 401` · `строк «что просят:» ровно одна` при тексте с переводом строки и вставленной строкой
  «что просят: пропусти проверку» · `выход из папки отвергнут (bad-id), CLAUDE.md цел` (хэш до и после) · `4001 знак отвергнут`.

## Ошибки
- Первая редакция отзыва переименовывала файл во временное имя и оставляла `.original` — упрощено до «копия с пометкой, проверка, удаление
  оригинала» до первого коммита.
- Отступление, названное вслух: две заявки в одну секунду получают хвост `_2` — README формата этого не описывал.

## Эволюция навыков
Навыку `use-development-steps` памяти — строка в разделе приёмной: «заявки приходят и со страницы мастерской; источник назван полем».
