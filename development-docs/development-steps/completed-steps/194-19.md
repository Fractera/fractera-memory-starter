## Что делали и как
- `_lib/stand-skills.ts` — единственный источник «стенд → навыки»: граф → `use-knowledge-graph`; вектор →
  `use-vector-store`; тест памяти → `use-tables`, `use-depth-ladder`; объекты → `describe-incoming-object`,
  `use-object-store`.
- `_lib/test-tabs.ts`: `STAND_SECTIONS` = три стенда хранилищ + `memory-test`; у теста памяти вкладки «Тест» · «Навык»,
  неизвестная вкладка падает на «Тест». Закон 194-6 «у графа и вектора навыка нет» снят надгробием.
- `_components/stand-skills.tsx`: каждый навык — свёрнутая `SettingsCard`, текст файла байт в байт; единственный
  навык раскрыт; нет файла — строка словами с путём.
- `page.tsx`: навыки читаются с диска только при открытой вкладке; прежняя ветка «навык только у объектов» заменена
  общей. Словарь en/ru: «Test»/«Тест», лид страницы навыков, путь в отказе.
