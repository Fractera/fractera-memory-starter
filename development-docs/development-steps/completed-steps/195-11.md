# 195-11 — вкладки «Оценка» всех стендов: порядок, удаление, текст «зачем и как»

**Коммиты:** `f04c470` порядок и удаление · `3b2a572` удалены неиспользуемые лиды. **Дата:** 2026-09-14. **Принят владельцем:** «принято».

## Что делали и как
Слово владельца: «сделай сортировку по дате опционально и сделай во всех кнопку удалить. Также напиши в заголовке этой вкладки зачем она нужна
как она работает без упоминания о том что это ещё не сделано».
- Порядок по дате — **на сервере** (`?order=asc|desc`, белым списком, по номеру случая). На экране «сначала старые» по последним 25 показывало бы
  старые из свежих, а не самые старые.
- Удаление **ровно одного случая по номеру** (`DELETE ?id=`), подтверждение вторым нажатием на экране, без всплывающего окна. Массового удаления
  дверью по-прежнему нет: без номера и метки — `400` (закон 189-5, вердикты человека не стираются пачкой), несуществующий номер — `404`.
- Лид «зачем и как» — один на все четыре стенда, из одного места словаря; свой лид внутри экрана убран, чтобы не было двух.
- Восемь неиспользуемых лидов `testBench.*.verdict` (4 стенда × en/ru) удалены, тип больше их не требует.

## Доказательства
**1. Прибор `scripts/probe/bench-cases-sort-delete.mjs` — `✓ OK`.** Два своих случая 117, 118; «сначала новые» — первым 118, номера убывают;
«сначала старые» — первым самый старый случай корпуса (70), номера растут; порядок-чушь → как «сначала новые»; удалён ровно 117, 118 на месте.
**2. Негатив и сборка.** Удаление без номера и метки → `400 no-case-or-mark`, корпус цел; несуществующий номер → `404 not-found`; без секрета
`401`; уборка, корпус 46 = 46. В сборке слова порядка 2 файла, новый лид 2, **старых лидов 0**.

## Ошибки
- ✗ Проверка «старого лида в сборке 0» сперва дала 2 — **ошибка образца, не правки**: фраза совпала с неиспользуемым лидом стенда графа в том же
  словаре. Лечение — точный образец и удаление самих лидов.
- ✗ Скрипт удаления лидов дал 0 совпадений с первого раза: **словарь в смешанных окончаниях строк** (1425 CRLF + 47 LF) — редактор на Windows
  пишет CRLF, скрипты LF. Образцы стали принимать оба вида. В git окончания нормализуются, на сервер едет архив из git.
