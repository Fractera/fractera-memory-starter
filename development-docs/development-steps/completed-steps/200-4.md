## Ошибки

## Эволюция навыков
`use-testing`: в странице с React текст вводится инструментом ввода расширения, а не скриптом; проверка «значение в состоянии» — по телу
панели «что уедет», а не по `value` поля; повторный ввод того же значения событием не считается — сначала сменить. Правка навыка — при
закрытии шага.
